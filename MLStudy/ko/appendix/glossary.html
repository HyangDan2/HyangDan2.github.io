공통 기호

기호 뜻
N, D 표본 수, 특징 수
X, xᵢ 관측 행렬, i번째 관측의 열벡터
θ, w, b 모델 파라미터, 가중치, 스칼라 절편
Φ 기저 변환을 적용한 설계행렬
μ, Σ, σ² 평균, 공분산, 분산
λ, σⱼ 문맥에 따라 고유값·승수, j번째 특잇값
η, α, C 학습률, 회귀 벌점, SVM 침범 비용
K, k 혼합 성분 수, PCA에서 선택한 성분 수
ᵀ, ‖·‖F 전치, Frobenius 노름
기호는 문맥과 함께

Σ는 공분산 또는 합 기호처럼 모양이 겹칠 수 있습니다. 각 식의 정의를 먼저 확인하세요. SVD의 Σ는 특잇값 행렬입니다.

용어 사전

용어 설명
표본 / Sample 분석의 한 관측 단위. 이 사이트에서는 데이터 행렬의 한 행.
특징 / Feature 예측 또는 구조 분석에 사용하는 입력 속성.
파라미터 / Parameter 정해진 모델 안에서 학습으로 추정하는 값.
하이퍼파라미터 차수·학습률·성분 수처럼 학습 설정을 정하는 값.
손실 / Loss 관측과 예측 사이의 비용. 목적에 맞춰 정의한다.
일반화 / Generalization 학습에 사용하지 않은 관측에서도 유용하게 작동하는 성질.
편향과 분산 모델링 가정의 체계적 오차와 표본 변화에 따른 추정의 변동.
랭크 / Rank 행렬의 독립인 열 또는 행의 수.
기저 / Basis 공간을 생성하는 선형독립 벡터 집합.
정사영 / Orthogonal projection 잔차가 부분공간에 직교하는 가장 가까운 투영.
고유값 / Eigenvalue 변환이 특정 방향을 유지하며 늘이는 비율.
특잇값 / Singular value SVD에서 직교 방향별 비음수 스케일.
Jacobian 벡터 출력의 입력별 1차 편미분 행렬.
Hessian 스칼라 함수의 2차 편미분 행렬.
우도 / Likelihood 관측을 고정하고 파라미터를 바꾸며 보는 관측 모형의 값.
사후분포 / Posterior 관측을 반영한 파라미터 또는 잠재변수의 분포.
정밀도 / Precision 분포 문맥에서는 분산 역수 또는 공분산 역행렬. 분류 평가의 precision과 구별.
설명분산 선택한 PCA 방향에서 보존되는 입력의 분산. 예측 정보의 비율이 아님.
책임값 / Responsibility 현재 혼합모형에서 한 관측의 성분별 사후 확률.
로그우도 우도의 로그. 여러 조건부 독립 관측의 기여가 합으로 표현됨.
마진 / Margin SVM 경계와 가까운 관측 사이의 기하학적 여유.
서포트 벡터 SVM 쌍대 계수가 0이 아닌 관측. Soft margin에서는 내부 점도 포함.
커널 / Kernel 특징 공간의 내적을 계산하는 함수. 적절한 준정부호 조건 필요.
정규화 / Regularization 모델 복잡도 등에 벌점을 추가하는 방법. 표준화와 구분.
표준화 / Standardization 훈련에서 얻은 평균·스케일로 특징 좌표를 변환하는 전처리.
