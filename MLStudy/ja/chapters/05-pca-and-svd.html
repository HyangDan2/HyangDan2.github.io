01 / 6つのセンサーに隠されている2つの要因

仮想環境センサーが6つのチャンネルを持ち、それぞれのチャンネルが2つの潜在的要因を異なる比率で測定するとします。もし共通の原因が2つある場合、重要な変化はより低い次元で表されることになります。ただし、各センサーには独立したノイズが存在するため、正確な値は2つの値よりも大きくなります。

この章の目標

正規化を行い、固有分解を施し、SVDとPCAを結合します。分散を最大化し、復元誤差を最小化する際に、どのようにして同じ方向を選ぶかを理解する必要があります。

基礎の次は発展事例3件 · 比較図4点発展部分 A /：信号の復元とノイズの復元を区別する必要があります。B /単位の変化が、PCAの方向に与える影響発展 C / 99.8%の分散保存によっても、分類に失敗する場合があります。

02 /の長さ、角度、影

内側のベクトルxᵀbは、その方向を示します。bが単位ベクトルである場合、xᵀbはその方向の座標です。xᵀb)bは影を表します。直交する単位ベクトルをBの列にまとめると、BᵀB = Iが得られます。

重要な式‖x‖₂ = √(xTx),   cos θ = xTb/(‖x‖₂‖b‖₂)
z = BTx,   x̂ = BBTx

x = [3,1]ᵀ を b = [1,1]ᵀ/√2 投影すると、[ 2,2]ᵀ ジャンカは、[ 1,−1]ᵀ ダ。ジャンカと b 内面は、… 0 したがって、元の長さの二乗は、投影された長さと残りの長さの二乗の合計に分けられます。

03 /の分散が大きい方向を見つけること

各チャンネルごとの平均値を引いて、Xを求めます。c共分散行列 S = XcᵀXc/ N 単位方向 b 投影された分散は、 bᵀSb また、単位長さの制約を組み合わせて微分すると、固有値問題になります。

重要な式maxb bTSb   subject to   bTb = 1
∇b[bTSb−λ(bTb−1)] = 0
Sb = λb

最も大きな固有値の方向は、最初の主成分です。後方の方向は、前方の方向と直交しており、残りの分散を最大限に保持します。S = [[4,2],[2,4]]の固有値は、6と2であり、その方向は斜めの2つの方向です。最初の成分は、全体の分散の75%を保持します。

平均値の除去と標準化

大きなスケールの特徴は、PCAに支配されることがあります。単位が異なるセンサーについては、標準化が適切かどうを判断する必要があります。この実験では、すべてのチャンネルで同じ無次元単位が使用されています。

04 /の分散が復元誤差である理由

正規職員全体において、座標の二乗和は、観測期間の二乗に等しい。上位… k 成分を元に戻すと、残った座標しか存在しない。観測値の平均を取ると、無効な方向の分散が加算されることになる。

重要な式X̂ = XcBkBkT
(1/N)‖Xc−X̂‖F² = Σj=k+1Dλj

誤差とは、各観測点におけるすべての特徴の二乗誤差の合計平均値のことです。特徴ごとに平均した値MSEは、Dで割る必要があります。互いに偏りのない共分散を得るために、N−1を使います。そして、固有値の合計にもN−1)/Nを乗じることで、現在の定義と一致させることができます。また、標準化された空間における誤差と、元の単位で表される誤差も区別する必要があります。

05 / SVDで同じ方向から取得する

Xc = UΣVᵀの場合、共分散はV(ΣᵀΣ/N)Vᵀです。Vの方向はPCAであり、σⱼ²/Nは分散です。共分散を最初に計算する必要はなく、SVDからPCAを求めることができます。

重要な式Xc = UΣVT,   λj = σj²/N
Xk = UkΣkVkT

SVDは、与えられたランク以下でFrobeniusの誤差を最小限に抑える近似手法です。PCAは、この手法を中心化されたデータに適用します。固有値が同じ場合、その部分空間内の方向性は一意ではないかもしれません。固有ベクトルの符号が変わっても、投影や復元の結果は同じです。 

import numpy as np
rng = np.random.default_rng(431)
latent = rng.normal(size=(180, 2))
A = np.array([[1,.1],[.8,.4],[-.4,.9],[.2,-.8],[.6,.6],[-.7,.2]])
X = latent @ A.T + .35*rng.normal(size=(180, 6))
mu = X.mean(0)
centered = X - mu
U, s, Vt = np.linalg.svd(centered, full_matrices=False)
k = 2
restored = (centered @ Vt[:k].T) @ Vt[:k] + mu
error = np.sum((X-restored)**2)/len(X)
print(error, np.sum(s[k:]**2)/len(X))

06 / の圧縮とノイズ除去の違い

実験では、180個の観測値と6チャンネルを使用します。成分の数、潜在因子間の相関関係、雑音の大きさを変えながら、保存される分散と誤差を比較します。同じデータに対しては、PCAを適用して復元するため、これはサンプル内の圧縮誤差です。

ノイズを除去する性能を評価するには、クリーンな信号や独立した評価が必要です。成分が多いほど、観測される復元誤差は減少しますが、それがクリーンな信号に近づくとは限りません。観測される復元と、潜在的な信号の復元を区別する必要があります。

全体の成分を使った場合は、どうなるのでしょうか？

数値の誤差を除外すれば、観測結果はそのまま復元されます。また、観測結果に含まれる雑音も一緒に復元されます。

説明の分散が95%の場合、分類情報も95%残っているのでしょうか？

いや、小さな分散方向においても、目標を区別するための情報があるかもしれない。その後、その成果をもって評価するべきだ。

発展部分のA ·成分の数と、ノイズの除去

考える問題 PCA の復元誤差がずっと減少していったら、純粋な信号もより正確に復元されるのでしょうか？

シード2505から、2つの潜在因子z~N(0,I₂), 6、そしてチャンネルx=Az+ε, ε~N(0,0.55²I₆)が生成される。Aの行は[1,.2], [.8,−.4], [−.6,.7], [.2,1], [.7,.5], [−.5,−.8]である。訓練には180個の特徴があり、独立した評価には400個の特徴がある。すべての特徴は無次元量である。平均や基底は、訓練データのみで推定される。

重要な式λⱼ=σⱼ²/N,   Bk=V[:,1:k]
x̂=(x−μtrain)BkBkᵀ+μtrain
  1. 訓練に焦点を当てた行列のSVDを求める。大きな2つの固有値は共通の要因を表している。残りの値は主に観測されるノイズを反映しているが、有限なサンプルでは、これらの値を正確に区別することはできない。
  2. k=0は、すべての入力信号を訓練時の平均値に復元するための基準線です。k=1~6を増やすことで、訓練時に観測されるノイズ、独立したノイズ、そして独立したクリーンな信号に対する二乗平均誤差をそれぞれ計算できます。
  3. この実行において、クリーンな信号の誤差は、 k=2 最小限の量で十分です。 k=2 その誤差は… 0.601, k=6 銀 1.768 もちろん、全体の成分を正確に再現することができます。
  4. 正確な答えは、合成実験によって得られるものです。実際のセンサーデータからこの指標をそのまま使用することはできません。そのため、繰り返し測定を行ったり、信頼性の高い基準信号を設定したり、後続の作業の性能などを評価する必要があります。
訓練によって失われた固有値の合計は、独立した評価の誤差と正確に同じですか？

この等式は、基底を求めた後の、中心化処理が行われた後の復元誤差に関して成り立ちます。他の観測値の共分散や平均値は変わる可能性があるため、独立した評価の誤差については、同じ数値の等式が成り立つとは一般的に言えません。

B /単位の変化が、PCAの方向に与える影響

発展：B ·単位の変更と標準化

考える問題 チャンネル 3 表示単位のみです。 20 交換してみたんですが、最初の成分が変わってしまいました。 PCA それは、間違っているのでしょうか？

前述の訓練結果から、チャンネル3を20倍に変更しただけです。情報内容は同じですが、数値の単位が変わっています。中心化処理を行った後のPCA、および訓練時のチャンネル標準偏差で割った値であるPCAの最初の成分を比較します。図では、不確定性を排除するために、最初の固有ベクトルの二乗値を使用しています。

  1. 中心化は、位置を移動させるだけで、尺度を合わせることはありません。一つの特徴を… 20 バーが増えると、その分散は… 400 また、他の特徴との相互相関も変化します。
  2. 標準化されていない最初の成分において、チャンネル3の二乗値は99.7%に等しい。数値の大きさが大きいチャンネルは、選択される方向をほぼ支配している。
  3. 訓練の結果から、平均値と標準偏差を基にしてZ=(X−μ)/sを算出し、その後PCAを適用します。推論の際にも、同じμ,sを使用します。これら2つのグラフのロードングは、それぞれ原始空間と標準化空間で定義された値です。
  4. 標準化というものは、常に正しいわけではありません。小さな分散が、正確な測定信号なのか、それともほぼ定数に近いノイズチャンネルなのかによって、単位分散として表される効果が異なります。物理的な意味や、その後の目的も考慮する必要があります。

標準化空間において、最小の復元誤差というのは、元の単位の二乗誤差も最小になるということでしょうか？

一般的にはそうではありません。標準化された空間では、円柱座標の残差を、チャネル標準偏差の二乗で割った重み付けされた誤差が最小になります。単位の選択によって、最適化される距離の意味が変わります。

発展 C / 99.8%の分散保存によっても、分類に失敗する場合があります。

発展されたC ·情報の保存の例外

考える問題 分散を99%以上維持できているのですが、分類の精度がコインを投げるようなレベルにまで低下する可能性はあるのでしょうか？

x₁は−8~8を等間隔に分けた100個の格子値です。各x₁にラベルy=−1,+1の観測を一つずつ置き、合計200件を作ります。x₂=0.2yとします。x₁は大きく変わりますがラベルと独立で、x₂は少ししか変わらなくてもラベルを完全に決めます。乱数を使わない対称な構成です。

重要な式Cov(x₁,x₂)=0,   Var(x₂)=0.04
PC1方向 =[1,0]ᵀ ⇒ x̂₂=0
  1. 最初の成分が保持する分散は、99.8%です。大きなx₁方向への変動が残るため、圧縮指標だけを見ても、非常に良いと言えます。
  2. 元々の空間では、すべてのラベルはsign(x₂)だけで決定されます。最初の成分を圧縮すると、同じx₁内で反対のラベルを持つ二つの要素が重なってしまいます。したがって、どんな決定的な分類法においても、このバランスの状態から50%を超えることはできません。
  3. この50%は、モデルが正しく学習されなかったために生じる数値ではありません。実際には、2つのラベルを区別するための情報が削除されたことで、限界が生じているのです。
  4. ビジコンバージョンの目的は、Xの分散や復元です。地図学習において使用される表現としては、成分の数や前処理などを訓練過程で決定し、分類の目的に合った独立した評価も行う必要があります。
説明の分散の目標を99%から99.9%に変更すると、この場合はどうなるでしょうか？

この構成では、最初の成分の比率が約99.8166%であるため、99.9%を満たすためには、2つの成分が必要です。しかし、一般的な分散閾値だけで、すべてのデータのラベル情報を保持できるという意味ではありません。
