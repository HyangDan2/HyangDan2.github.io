01 / 같은 조건에서도 값은 달라진다

가상 예약 알림이 목표 시점보다 몇 초 빠르거나 늦게 도착하는지 측정하자. 부호가 있는 시간 오프셋은 같은 조건에서도 달라진다. 관측을 평균 μ, 알려진 표준편차 σ의 가우시안으로 모델링하면 변동과 평균 추정을 분리할 수 있다.

이 장의 목표

질량과 밀도, 우도와 사후분포를 구분한다. 가우시안 사전분포와 L2 정규화가 연결되는 조건을 설명한다.

02 / 확률은 사건에, 밀도는 위치에

확률공간은 결과의 집합 Ω, 사건들의 집합, 확률 측도로 구성한다. 확률변수는 결과를 수치로 보내는 함수다. 이산 변수는 확률을 더하고 연속 변수는 구간 밀도를 적분한다.

핵심 식P(a ≤ X ≤ b) = ∫abp(x)dx
F(t) = P(X ≤ t)

[0,0.2]에서 균일한 분포의 밀도는 5다. 밀도는 1을 넘을 수 있지만 전체 적분은 1이다. 연속분포에서 한 점의 확률은 0이므로 p(x)를 “정확히 x일 확률”이라고 읽으면 안 된다.

가우시안 밀도p(x) = [1/(σ√(2π))] exp(−(x−μ)²/(2σ²))

μ는 위치, σ²는 퍼짐을 정한다. 다차원 공분산은 방향별 퍼짐과 함께 변하는 정도를 나타낸다. 밀도는 변수 단위가 바뀌면 수치도 바뀐다.

03 / 조건을 뒤집는 계산

곱 규칙 p(a,b) = p(a|b)p(b)와 p(a,b) = p(b|a)p(a)를 같게 놓으면 베이즈 정리를 얻는다. 분모는 가능한 원인에 대해 합하거나 적분한다.

핵심 식p(θ|D) = p(D|θ)p(θ)/p(D)
p(D) = ∫p(D|θ)p(θ)dθ
요소 의미
사전 p(θ) 관측 전 파라미터에 대한 모델
우도 p(D|θ) θ를 고정했을 때 관측의 그럴듯함
사후 p(θ|D) 관측을 반영한 파라미터 분포

A가 요청 80%, B가 20%를 담당하며 지연 확률이 각각 0.05,0.20이라고 하자. 지연을 봤을 때 B일 확률은 (0.20×0.20)/(0.80×0.05+0.20×0.20) = 0.5다. 지연이 B에서 더 흔하다는 사실만으로 지연 요청 대부분이 B라고 단정할 수 없다.

04 / 관측을 가장 그럴듯하게 만드는 평균

오프셋 y = [2,3,4,3]초가 조건부 독립이고 σ = 2초라고 하자. 우도는 밀도의 곱, 로그우도는 합이다. μ와 무관한 항을 빼면 제곱오차 최소화가 남는다.

핵심 식log p(y|μ) = 상수 − (1/(2σ²))Σi(yi−μ)²
μ̂ML = (1/N)Σiyi = 3초

MLE는 파라미터의 분포 대신 우도가 가장 큰 점을 고른다. σ도 미지수라면 가우시안 MLE 분산의 분모는 N이다. 불편 표본분산의 분모 N−1과 목적이 다르다.

05 / 적은 관측에 사전분포 더하기

μ의 사전분포를 평균 μ₀ = 0, 분산 τ² = 1인 가우시안으로 둔다. 우도와 곱한 뒤 μ에 관한 제곱을 완성하면 사후분포도 가우시안이다. 분산 역수인 정밀도가 더해진다.

핵심 식vpost = (1/τ² + N/σ²)−1
mpost = vpost(μ₀/τ² + Σiyi/σ²)

위 관측에서는 vpost = 1/2, mpost = 1.5초다. 가우시안의 평균과 최빈값이 같으므로 MAP도 1.5초다. 다음 관측의 예측 분산은 σ² + vpost = 4.5로, 관측 잡음과 평균 추정 불확실성을 모두 포함한다.

import numpy as np
y = np.array([2.,3.,4.,3.])
sigma2, prior_var, prior_mean = 4., 1., 0.
post_var = 1/(1/prior_var + len(y)/sigma2)
post_mean = post_var*(prior_mean/prior_var + y.sum()/sigma2)
print("MLE:", y.mean(), "MAP:", post_mean)
print("predictive variance:", sigma2 + post_var)

06 / MAP와 정규화의 연결

회귀 잡음이 독립 N(0,σ²), 기울기 계수 사전이 독립 N(0,τ²)이면 음의 로그 사후분포가 제곱오차와 L2 벌점의 합이 된다. 절편에는 여기서 벌점을 주지 않는다.

잔차 제곱합 Ridge와의 대응−log p(θ|X,y) = 상수 + ‖y−Φθ‖²/(2σ²) + ‖θ기울기‖²/(2τ²)
α = σ²/τ²

관계는 모델링 가정과 손실 스케일을 지정했을 때 성립한다. MAP 점 하나가 전체 사후 불확실성을 대신하지는 않는다.

표본 수가 커지면 사전 영향은 어떻게 되는가?

이 가우시안 예제에서 분산을 고정하면 N/σ²가 커져 사후 평균이 표본평균에 가까워진다.

MAP는 MLE보다 항상 좋은가?

아니다. 잘못된 강한 사전은 예측을 악화시킬 수 있다. 표본 수·복잡도·가정의 적합성을 검증해야 한다.

심화 A / 실패 확률의 사후분포를 순차 갱신하기

심화 A · 순차 베이즈 갱신

풀어볼 문제 20번의 요청에서 실패가 2번, 다음 80번에서 7번이었다. 실패 확률을 하나의 비율 대신 분포로 업데이트해 보자.

요청 실패를 조건부 독립 Bernoulli(p)로 가정한다. 사전은 Beta(2,18), 평균 0.1이다. 처음 20개 중 실패 2개를 관측하면 Beta(4,36), 이후 80개 중 실패 7개를 추가하면 Beta(11,109)가 된다. 고정된 가상 집계이며 난수로 집계를 바꾸지 않는다.

핵심 식p(p|s,n) ∝ pa+s−1(1−p)b+n−s−1
Beta(a,b) → Beta(a+s,b+n−s)
E[p|D]=(a+s)/(a+b+n),   P(다음 실패|D)=E[p|D]
  1. 우도 pˢ(1−p)ⁿ⁻ˢ를 사전의 거듭제곱에 곱한다. 실패와 성공의 개수가 각각 Beta 파라미터에 더해진다.
  2. 앞선 사후분포를 다음 블록의 사전으로 사용한다. 마지막은 a=2+2+7=11, b=18+18+73=109다. 총 100개를 한꺼번에 처리해도 같다.
  3. 사후 평균은 9.2%, 다음 한 건의 실패 예측 확률도 같은 값이다. 실패 확률 p 자체의 95% 등꼬리 신용구간은 약 4.7%~14.9%다.
  4. 구간은 사후 밀도를 수치 적분한 누적분포의 2.5%·97.5% 지점이다. “이 모델과 관측을 조건으로 p가 이 구간에 있을 사후확률 95%”라고 읽는다. 다음 100건의 실패 횟수 구간과는 다르다.
단계 분포 평균 95% 신용구간(근사)
관측 전 Beta(2,18) 10.0% 1.3% ~ 26.0%
20개 관측 후 Beta(4,36) 10.0% 2.9% ~ 20.9%
100개 관측 후 Beta(11,109) 9.2% 4.7% ~ 14.9%
시간이 지나면서 실제 실패율이 바뀌어도 관측을 무조건 누적하면 되는가?

고정 p와 조건부 독립 가정이 맞지 않으면 오래된 관측이 현재 상태를 왜곡한다. 구간별 모델, 시간 변화 모형 또는 잊기 가중치를 별도로 설계하고 시간 순서 평가로 확인해야 한다.

심화 B / 경보를 기저율과 비용으로 다시 해석하기

심화 B · 기저율과 비대칭 손실

풀어볼 문제 탐지 민감도 90%인 경보가 울렸다면 고장 확률도 90%인가? 그리고 언제 조치해야 할까?

가상 점검 시스템의 고장 비율 π=2%, 민감도 90%, 특이도 96%를 가정한다. 10,000건의 기대 횟수로 풀면 고장 200건 중 경보 180건, 정상 9,800건 중 오경보 392건이다. 이는 모형에 따른 기대 횟수이며 1장의 난수 점수 표본과는 다른 계산이다.

핵심 식P(고장|경보)=0.9π / [0.9π+0.04(1−π)]
π=0.02 ⇒ 180/(180+392) ≈ 31.5%
  1. 조건부 확률의 방향을 먼저 적는다. 민감도는 P(경보|고장), 궁금한 확률은 P(고장|경보)다.
  2. 경보 중 실제 고장 비중에는 정상 장비에서 발생한 오경보도 분모에 들어간다. 기저율이 낮으면 이 항이 커질 수 있다.
  3. 이제 q를 보정된 개별 고장 확률이라고 하자. 정상인데 조치하는 비용은 1, 고장인데 무시하는 비용은 25, 올바른 조치의 비용은 0으로 단순화한다.
  4. 조치 기대 손실 1−q와 무시 기대 손실 25q를 비교하면 q>1/26≈3.85%에서 조치한다. 50%가 자동 기준이 되는 것은 아니다. 동률에서는 두 행동의 기대 손실이 같다.
SVM의 결정 점수 f(x)에 1/26을 바로 적용할 수 있는가?

아니다. f(x)는 이 예제의 보정된 확률 q가 아니다. 확률 보정이나 별도 검증 비용 곡선을 통해 점수의 의사결정 임계값을 정해야 한다. 확률 보정에 쓴 데이터도 최종 테스트와 분리한다.

심화 C / 다음 관측의 불확실성까지 계산하기

심화 C · 평균 불확실성과 관측 잡음

풀어볼 문제 평균 지연 시간을 매우 정확히 알아도 다음 한 번의 지연 시간이 정확해지지 않는 이유를 계산해 보자.

지연 편차 yᵢ|μ~N(μ,4)초², μ~N(0,9)초²로 둔다. N=1,2,5,10,20,50,100,300에서 표본평균을 모두 2초로 고정하여 표본 크기의 효과만 비교한다. 실제로 같은 난수 표본을 누적한 경로가 아니라 표본평균에 조건부인 해석적 비교다.

핵심 식vN=(1/9+N/4)−1,   mN=vN(2N/4)
μ|D~N(mN,vN)
ynew|D~N(mN,4+vN)
  1. 사후 정밀도는 사전 정밀도 1/9와 데이터 정밀도 N/4의 합이다. 관측이 늘수록 평균의 사후 분산은 감소한다.
  2. N=300에서 평균의 사후 표준편차는 0.115초다. 다음 관측의 예측 표준편차는 2.003초로 여전히 약 2초다.
  3. 전체 분산 법칙으로 조건부 관측 분산 4와 평균 추정 분산 vN을 더한다. 평균의 추정 오차와 개별 관측의 무작위 변동은 다른 항이다.
  4. 관측 잡음을 줄이려면 센서·서비스 과정 자체를 개선하거나 설명력을 가진 특징을 추가해야 한다. 같은 분포의 표본을 더 수집하는 것만으로 가정된 관측 분산 4는 사라지지 않는다.
계산 코드의 핵심 펼치기

심화 Python의 해당 함수에서 발췌한 계산 흐름입니다. 전체 데이터 생성·보조 함수는 아래 다운로드에 있습니다.

n = np.array([1, 2, 5, 10, 20, 50, 100, 300])
posterior_variance = 1 / (1/9 + n/4)
posterior_mean = posterior_variance * (2*n/4)
mean_sd = np.sqrt(posterior_variance)
new_observation_sd = np.sqrt(4 + posterior_variance)
print(np.c_[n, posterior_mean, mean_sd, new_observation_sd])
