Experiment conditions and how to read the results

J(u,v) = (u²+κv²)/2. Without preconditioning, update [u,v] ← [u,v]−η[u,κv]. Global convergence for this problem requires 0<η<2/max(1,κ). Axis preconditioning multiplies the gradient by diag(1,1/κ), changing the convergence range to 0<η<2.

Coordinates and loss are dimensionless. Paths outside the original coordinate window are clipped, but the log10 loss plot includes all executed steps. Stop as converged below loss 10⁻¹⁰, or as divergent above 10¹².

  1. At κ=6, compare η=.15 and .4.
  2. Enable axis preconditioning with the same start and learning rate.
  3. Start at the origin and interpret the stopping status.
