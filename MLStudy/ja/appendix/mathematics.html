線形代数 · 解と空間

ベクトルの線形結合 Σαᵢvᵢ 作られる集合を span そう言われています。 0 作る組合が、すべての… αᵢ = 0 それは、線形独立な集合です。空間を構成する線形独立な集合の基底は、その基底ベクトルの数が次元数に等しい。ランクは、行列の列数であり、独立な行の数と等しいです。

2u+v=5, 4u+3v=11の2番目の行において、1番目の行の値に−2倍を加えると、v=1となります。また、u=2にもなります。行の交換や、0以外の定数倍、または他の行の値を足すという操作は、元の集合を維持します。台形において、ピボットを超えない列の変数は、自由変数です。最後の行が[0,0|1]の場合、矛盾は存在しません。

重要な式A = [[1,2,3],[0,1,1]]
Ax = 0 ⇒ x = t[−1,−1,1]T
rank(A) = 2,   dim ker(A) = 1

線形写像 Tは、T(αu+βv)=αT(u)+βT(v)を満たします。変換行列のj番目の列は、入力基底のj番目のベクトルが出力基底において持つ座標です。基底を変えると、座標や行列の表現は変わりますが、同じ写像を表すことができます。

B,Cが正方行列である場合[T]C←B = C−1AB

単面では、出力空間全体が0だけで構成されている。一方、全平面では、出力空間全体が全平面となっている。どちらも満たされている場合、それは全平面である。回転行列[[cosθ,−sinθ],[sinθ,cosθ]]では、長さが保持され、[[2,0],[0,1]]では、最初の座標が増加する。

幾何 · ノルムと正射影

賭け事とは、非線形性、正の性質、絶対的な同時性、三角方程式を満たす長さの関数です。x=[3,−4]のL1賭け事は、7, L2賭け事は5です。内積は賭け事を導き出しますが、すべての賭け事が内積から生じるわけではありません。L1は平行四辺形の法則を満たしません。

Cauchy–Schwarz 不等式|xTy| ≤ ‖x‖₂‖y‖₂

直交行列QはQᵀQ = QQᵀ = Iに直交しているため、長さと角度が保存されます。0ベクトルはすべてのベクトルに直交しますが、正則化することはできません。部分空間Uと直交空間U⊥の次元の和は、全体の次元に等しいです。すべてのxは、これら2つの空間のベクトル和によって唯一に表されます。

重要な式P = B(BTB)−1BT   (Bの温度が独立している)
P² = P,   PT = P

正射影とは、与えられた部分空間内でユークリッド距離を最小限に抑えるような射影のことです。P²=Pを満たす射影が必ずしも正射影であるとは限りません。対称性も必要です。PCAは、この部分空間そのものをデータから選び出すものです。

行列分解 · 構造を明らかにする

行列の行列式とは、正方行列の符号付きの倍率のことです。0の場合、それは非可逆行列です。2×2の行列の行列式は、a,b],[c,d]]の行列式にad−bcを掛けたものです。三角行列は、対角成分の積であり、対角成分の和は固有値の和に等しいです。traceは、対角成分の和であり、これは固有値の和と等しいです。

重要な式Av = λv,   v ≠ 0
A = VΛV−1   （独立な固有ベクトルが十分にある場合）

すべての正方行列が対角化されるわけではありません。[[1,1],[0,1]]]では、固有値1が重複していますが、独立な固有ベクトルは1つだけです。実対角行列は、直交基底によって対角化されます。正の重複行列の場合、すべての0ではxとなり、xᵀAx>0となります。

Choleskyの分解[[4,2],[2,3]] = LLT,   L = [[2,0],[1,√2]]

微分 · 連鎖律と誤差逆伝播

f(x,y)=x²y+sin yの勾配は[2xy, x²+cos y]ᵀです。ベクトル関数g(x,y)=[x²+y,xy]ᵀのJacobianは[[2x,1],[y,x]]です。入力と出力がともに2次元なので2×2ですが、一般には出力数 × 入力数の形になります。

重要な式Jf∘g(x) = Jf(g(x))Jg(x)

ニューラルネットワークのある層をh=σ(Wx+b)とし、損失をLとします。δ=(∂L/∂h)⊙σ′(Wx+b)であれば、∂L/∂W=δxᵀ, ∂L/∂b=δ, ∂L/∂x=Wᵀδとなります。この情報を、前の層に伝達します。非線形活性化関数の微分不可能な点については、選択された部分の傾きを使用して実装します。

中心差分検証∂f/∂xj ≈ [f(x+hej)−f(x−hej)]/(2h)

確率 · 和、条件付き確率、共分散

合成分布において、他の変数を加算したり、積分を行うと、周辺分布が得られます。独立変数の場合、合成分布は周辺分布の積に分解されますが、相関係数が0である場合、一般的には独立ではありません。Xが対称分布であり、Y=X²の場合、共分散が0になることもありますが、それは従属関係です。

重要な式E[X] = Σxxp(x)   または ∫xp(x)dx
Cov(X,Y) = E[(X−E[X])(Y−E[Y])]
Var(X) = E[X²]−E[X]²

共分散は正の準正則行列です。任意のaに対して、aᵀΣaは線形結合aᵀXの分散であり、負の値にはなりません。多変量ガウス分布の場合、共分散0を持つ成分は独立ですが、これは特別な性質です。

重要な式N(x|μ,Σ) = exp[−½(x−μ)TΣ−1(x−μ)] / √((2π)Ddet Σ)

上の密度式は、Σが正の整数である場合の全空間の密度です。特異共分散は、低次の次元の部分空間において質量が集中しているため、行列や行列式をそのまま使用することはできません。

非等式 gᵢ(x)≤0 には、乗数が含まれています。 λᵢ≥0 相補性 λᵢgᵢ(x)=0 これが追加されます。有効な制約とそうでない制約を区別するものです。 KKT 条件です。凸性や規則性といった条件を確認する必要があります。そうすることで、最適性が保証されます。

復習問題

固有分解とSVDは、いつ同じになるのでしょうか？

実対称な正の準正行列の場合、特異値は負の値にはならないため、固有ベクトルを使ってSVDを構成することができます。一般的な行列では、特異値は常に非負の値ですが、特異値は負の値や複素数になることもあります。

訓練データのPCAの共分散の分母を変えると、方向も変わってしまうのでしょうか？

NとN−1の違いは、正の定数倍であるため、方向は同じです。固有値だけが比例して変化します。誤差の等式のスケールも調整する必要があります。

L1とL2のうち、どちらの損失が異常値に対してより敏感なのでしょうか？

大きな誤差において、L2の変化率は誤差に比例して大きくなります。一方、L1の部分曲がりの大きさは一定です。特定のデータの係数の変化や安定性については、設計行列や解の唯一性も考慮する必要があります。
