01 / 長くて狭い谷

二つの座標u,vにおいて、J = (u² + κv²)/2の地形があるとします。κが大きい場合、v方向は急であり、u方向は緩やかです。同じ歩幅で動く場合、急な方向では谷を越えることができます。モデルの学習における多くの困難は、このような異なる方向における曲率に起因しています。

この章の目標

一度の更新を手動で計算する。収束条件を学習率と勾配で表現し、連鎖法則やJacobian·SGDの役割を明確に区別する。

02 / の微分を合計すると、傾きが得られます。

偏微分とは、他の変数を固定し、ただ一つの変数のみを変動させたときの変化率のことです。傾きとは、偏微分をまとめたベクトルです。小さな変動Δθに対する関数の変化は、傾きと変動の内挿によって表されます。

重要な式∇J(u,v) = [u,κv]T
J(θ + Δθ) ≈ J(θ) + ∇J(θ)TΔθ

同じユークリッド長さを持つ移動経路において、負の傾きの方向で最も多くの近似が可能になるのは、1次の近似です。あまり遠くに移動すると、近似が崩れてしまいます。また、傾きが0の場合でも、最小点というわけではありません。u² − v²の原点は、アンジュポイントです。Hessianは、2次の偏微分行列であり、正の向きの場合は、厳密な局所的最小点となります。

03 / 合成関数の変化率の伝達

p = wx + b, L = (p − y)²/2を見てみましょう。wは、予測されたpを経て損失に至ります。各接続における変化率を掛け合わせることで、最終的な変化率が得られます。

重要な式∂L/∂p = p − y,   ∂p/∂w = x
∂L/∂w = (p − y)x,   ∂L/∂b = p − y

x = 2, y = 5, w = 1, b = 0の場合、損失は4.5, wであり、傾きは−6です。学習率が0.1の場合、w,bを一緒に更新すると、結果は1.6,0.3となり、損失は1.125になります。

ベクトル出力の微分をまとめる Jacobian 出力は行であり、入力は列です。 Jf∘g = JfJgこれが成り立つ。逆伝播法では、全てのJacobianを作るのではなく、損失から出発するベクトルと、各層のJacobianの積を逆に計算するのだ。

04 / 学習率の安定性条件

二次の目的関数において、uは毎回1 − η倍、vは1 − ηκ倍の割合で変化します。二つの絶対値が1より小さい場合、すべての初期点から原点に収束します。

この実験における正確な収束条件θt+1 = θt − η∇J(θt)
ut+1 = (1 − η)ut
vt+1 = (1 − ηκ)vt
0 < η < 2/max(1,κ)

κ = 6の場合、ηは1/3よりも小さくなければならない。0.15と0.4を比較してみよう。境界値では、減少しない振動が生じる可能性がある。一般的な非線形モデルでは、すべての点の曲率を知るのは困難であるため、損失の変化や終端条件を同時に管理する必要がある。

05 / 座標の調整と確率的な更新

実験における「軸の補正」とは、v方向の傾きをκで割るという処理です。つまり、2つの方向が同じ比率で減少するということです。これは、適切な座標変換によって理解することができます。特徴量の標準化も有効かもしれませんが、いつもこのような完璧な補正ができるわけではありません。

重要な式θt+1 = θt − η diag(1,1/κ)∇J(θt)

SGD 小さなランダムな配置を用いて、全体の傾きを推定することで、計算コストを削減することができます。均一なサンプル抽出などの条件下では、不都合な推定量が生じますが、個々のステップでの損失は増加する可能性があります。配置のサイズや学習率は、コストと変動性の両方に影響を与えます。 

import numpy as np
point = np.array([3., 2.])
kappa, rate = 6., .15
losses = []
for step in range(45):
    losses.append((point[0]**2 + kappa*point[1]**2)/2)
    point -= rate*np.array([point[0], kappa*point[1]])
print("final point:", point)
print("loss decreased:", losses[-1] < losses[0])

06 /実験と検証

曲率を2,6,12に変更し、安定した学習率の範囲が狭くなるかを確認する。同じ設定で、軸の補正前後の結果を比較する。固定された座標軸の外側にある経路は表示されない。損失が10¹²を超えた場合は、繰り返しを中止する。

傾斜の実装は、どのようにして検証されるのでしょうか？

各座標に小さなhを加算し、引いた値を2hで割った差を、中央値と比較します。hが小すぎると、浮動小数点数値の誤差が大きくなります。

非常に小さい学習率では、すべての問題を解決できるのでしょうか？

収束の速度が遅くなる可能性があり、また、アンチャウントポイントや局所的最小値、誤った傾きの問題もすべて解決されない。

深層のA /で回転する谷において、3つの最適化手法を比較する。

発展 A ·：回転後の曲率とモーメント

考える問題 軸と平行ではない、狭い渓谷の中で、GDとNewtonはどのような経路を選ぶのでしょうか？

J(w)=½wᵀHw, H=R diag(1,30) Rᵀであり、Rは36°の回転行列です。始点は[3,−2]ᵀ]であり、最小値は原点です。80回の更新を経て、GD(η=0.06), heavy-ballのモーメントン(η=0.07, β=0.65), Newton(η=1))が比較されます。これは決定性実験であり、すべての座標は無次元です。

重要な式GD: wt+1=(I−ηH)wt
Momentum: vt+1=βvt+Hwt,   wt+1=wt−ηvt+1
Newton: HΔ=∇J(w),   w←w−Δ
  1. GD 固有ベクトル座標に変換すると、誤差はそれぞれ以下のようになります。 1−ηλ それだけに、倍増されます。 η=0.06 では、 λ=1 方向が 0.94, λ=30 方向が −0.8 そして、ゆっくりとした減少と、振動が同時に現れます。
  2. モーメントは、過去の移動量を累積して計算されます。ηがGDの上限値2/30よりも大きくても、同じ単純な条件GDをそのまま適用することはできません。各固有方向の特性方程式r²−(1+β−ηλ)r+β=0の根の大きさを確認する必要があります。
  3. 80回後には、損失はGD 3.93e-05となり、モーメントは4.63e-15です。この数値は、指定された二次式と設定の結果に基づくものです。ただし、これはすべての損失においてモーメントが速いという意味ではありません。
  4. Newton この二乗方程式から、正確な値を求めることができます。 Hessian それを解いて、一度に元の位置に戻す。大規模なモデルでは、線形計画法の計算量が大きくなります。また、非凸問題の場合も同様です。 Hessian 同じ性質を持つとは限りません。
現在、Hに、対称成分の逆数を乗じた値は、Newtonと等しくなりますか？

いいえ。回転により非対角成分がゼロではありません。diag(H)の逆数は座標ごとの大きさを調整するだけで、軸間の結合を除けません。この例のNewton法はH全体の線形方程式を解きます。

発展B / ロジスティック勾配を中心差分で検証する

発展 B · ロジスティック損失の傾きの検査

考える問題 直接微分によって得られたベクトル勾配を信頼する前に、数値微分によって確認してみましょう。

切片を含む6×3計画行列の行は[1,−2,.5]、[1,−1,1]、[1,−.5,−1]、[1,.5,.2]、[1,1,−.7]、[1,2,1.2]です。y=[0,0,1,0,1,1]、検査点w=[.2,−.3,.4]とします。正則化なしの平均二値交差エントロピーを使います。

重要な式J(w) = (1/N)Σ[log(1+exp(xᵢᵀw))−yᵢxᵢᵀw]
∇J = Xᵀ(sigmoid(Xw)−y)/N
gⱼFD=[J(w+heⱼ)−J(w−heⱼ)]/(2h)
  1. log(1+exp(z))をそのまま計算すると、大きなzからoverflowまでの値が得られます。NumPy logaddexp(0,z)についても、同じ値を安定して計算できます。
  2. 解釈可能な傾きは、[0.065, -0.534, 0.256]]です。熱ベクトルの大きさは3であり、各項の符号は、そのパラメータが増加する際の損失の変化の方向を示しています。
  3. hを10⁻¹~10⁻¹⁰に変えて、最大絶対差を求めます。この実行における最小絶対差は5.58e-12です。hがあまりにも大きすぎると、切り捨て誤差が生じます。一方、hがあまりにも小さすぎると、二つのほぼ同じ値の減算誤差が生じます。
  4. 複数のパラメータの値や入力の大きさを考慮して判断します。一つの点の一致だけで、全体の学習コードが正しいと結論付けることはありません。
計算コードの要点を開く

発展Pythonの対応する関数から計算の流れを抜粋しています。完全なデータ生成と補助関数は以下のダウンロードにあります。

def loss(w):
    z = X @ w
    return np.mean(np.logaddexp(0, z) - y * z)
p = 1 / (1 + np.exp(-(X @ w)))
gradient = X.T @ (p - y) / len(y)
h = 1e-5
numeric = np.array([(loss(w+h*e)-loss(w-h*e))/(2*h)
                    for e in np.eye(len(w))])
print(np.max(np.abs(numeric - gradient)))

深化 C / SGD そのノイズのレベルを予測する方法

発展されたC · SGDのノイズレベル

考える問題 平均的に、正しい傾度を使用しても、損失が0にまで下がらない理由を、式を用いて予測してみましょう。

スカラー損失はJ(w)=λw²/2, λ=4を使用します。ミニバッチの傾斜はg=λw+ξ, Eξ=0, Varξ=σg²/Bでモデル化されます。σg=2, η=0.1、開始時の値はw=2です。実際のデータセットをバッチに分ける代わりに、バッチのサイズに応じてガウス分布の傾斜を直接生成する、という単純化された実験です。シード値は2303、各Bごとに2,048個の独立した経路の平均を取ります。

重要な式wt+1=(1−ηλ)wt−ηξt
V∞=(1−ηλ)²V∞+η²σg²/B
E[J]∞=ησg² / [2B(2−ηλ)]
  1. 傾斜のノイズが現在、 w そして、独立している。| 1−ηλ|<1の場合、有限な正規分布を得ることができます。ここでは、1−ηλ=0.6を考えます。
  2. 初期値の効果がなくなった後も、毎回新しいノイズが入ってくるため、定数の学習率は一定のロスレッジバースを形成します。
  3. B=1,16,64の理論的な損失の底は、それぞれ0.125, 0.0078125, 0.001953125となります。同じ学習率で、エポック数を16倍に増やすと、この単純なモデルの正規化損失は1/16になります。
  4. 学習率を下げても、ノイズレベルは低くなりますが、初期の収束速度は遅くなります。ブロッキングの計算コスト、データの相関性、非線形損失の場合には、この式をそのまま性能保証として使用することはできません。
GDが静かな状態のままにしておき、ηをそのままにしておくと、このような損失の底が残るのでしょうか？

σg=0の場合、理論上の正常な損失は0です。安定した学習率の場合、初期の誤差は指数関数的に減少します。現在の状態は、定数的な学習率によって、新しい傾きやノイズが継続的に与えられている結果です。
