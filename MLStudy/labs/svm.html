Experiment conditions and how to read the results

The linear soft-margin SVM objective is ½‖w‖² + CΣmax(0,1−yᵢ(wᵀxᵢ+b)). The intercept is not penalized. C ranges from .01~10; the slider controls log10(C). No kernel is used.

Train on 24 observations for each balanced label −1,+1 and validate on 160 observations from an independent seed. With independent standard-normal a,b, generate x₁=1.15y+σa and x₂=s(.55y+.3a+.8b). All features are dimensionless and synthetic. The training seed is selected; the validation seed is that value+10000. Enabling the outlier adds one training point at [−2.6,−1.6s] with label +1.

Standardization uses only training means and standard deviations. For comparison, plots always convert back to the original feature coordinates. Margin width 2/‖w‖ is a distance in training coordinates, so values before and after standardization are not directly comparable in the same units. Check whether changing only feature scale while standardizing preserves predictions.

Update two dual coefficients together to preserve Σαᵢyᵢ=0 and 0≤αᵢ≤C. Allow at most 8000 updates; report convergence only when the relative primal-dual gap is ≤10⁻⁵ and KKT violation is ≤10⁻³. Unconverged results are current approximations. Outlines indicate observations with αᵢ>10⁻⁷; in soft-margin SVM these may include points inside the margin or misclassified observations.

  1. Reduce overlap, then compare margins across C values.
  2. Add an outlier and increase C to observe the boundary change.
  3. Increase the feature scale, then switch standardization on and off.
  4. Read accuracy together with the confusion matrix. Repeatedly compared validation accuracy is not final test performance.
