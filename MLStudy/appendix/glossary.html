Shared notation

Symbol Meaning
N, D Number of samples; number of features
X, xᵢ Observation matrix; column vector for observation i
θ, w, b Model parameters; weights; scalar intercept
Φ Design matrix after basis transformation
μ, Σ, σ² Mean; covariance; variance
λ, σⱼ Eigenvalue or multiplier depending on context; jth singular value
η, α, C Learning rate; regression penalty; SVM violation cost
K, k Mixture component count; selected PCA component count
ᵀ, ‖·‖F Transpose; Frobenius norm
Read symbols in context

Σ can denote a covariance matrix or resemble a summation symbol. Check the definition in each equation. In SVD, Σ is the singular-value matrix.

Glossary

Term Explanation
Sample One unit of observation; here, one row of the data matrix.
Feature An input attribute used for prediction or structural analysis.
Parameter A value estimated through learning within a specified model.
Hyperparameter A value specifying the learning setup, such as degree, learning rate, or component count.
Loss The cost between observations and predictions, defined for the task.
Generalization The ability to work usefully on observations not used in training.
Bias and variance Systematic error from modeling assumptions and variability of estimates across samples.
Rank The number of linearly independent columns or rows of a matrix.
Basis A linearly independent set of vectors spanning a space.
Orthogonal projection The closest projection whose residual is orthogonal to the subspace.
Eigenvalue The scale factor along a direction that a transformation preserves.
Singular value A nonnegative scale along an orthogonal direction in SVD.
Jacobian The matrix of 1st-order partial derivatives of a vector output with respect to its inputs.
Hessian The matrix of 2nd-order partial derivatives of a scalar function.
Likelihood The observation model's value viewed as a function of parameters while observations are fixed.
Posterior A distribution of parameters or latent variables updated with observations.
Precision In distributions, inverse variance or the inverse covariance matrix. Distinguish this from classification precision.
Explained variance Input variance retained along the selected PCA directions, not a fraction of predictive information.
Responsibility The posterior probability of each component for an observation under the current mixture model.
Log likelihood The logarithm of likelihood; contributions from conditionally independent observations add together.
Margin The geometric clearance between an SVM boundary and nearby observations.
Support vectors An observation whose SVM dual coefficient differs from 0. Soft-margin support vectors can lie inside the margin.
Kernel A function computing an inner product in feature space, subject to an appropriate positive-semidefinite condition.
Regularization A method that adds a penalty, for example on model complexity. Distinguish it from standardization.
Standardization Preprocessing that transforms feature coordinates using means and scales obtained from training data.
