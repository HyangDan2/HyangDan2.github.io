01 / 여섯 센서에 숨은 두 요인

가상 환경 센서 여섯 채널이 두 잠재 요인을 서로 다른 비율로 측정한다고 하자. 공통 원인이 두 개라면 중요한 변화는 더 낮은 차원으로 표현할 수 있다. 다만 센서마다 독립 잡음이 있으면 정확한 랭크는 둘보다 커진다.

이 장의 목표

정사영을 계산하고 고유분해·SVD와 PCA를 연결한다. 분산 최대화와 복원 오차 최소화가 같은 방향을 선택하는 이유를 이해한다.

02 / 길이, 각도, 그림자

내적 xᵀb는 방향 관계를 나타낸다. b가 단위벡터이면 xᵀb는 그 방향 좌표, (xᵀb)b는 그림자다. 직교 단위벡터를 B의 열에 모으면 BᵀB = I이다.

핵심 식‖x‖₂ = √(xTx),   cos θ = xTb/(‖x‖₂‖b‖₂)
z = BTx,   x̂ = BBTx

x = [3,1]ᵀ를 b = [1,1]ᵀ/√2로 투영하면 [2,2]ᵀ, 잔차는 [1,−1]ᵀ다. 잔차와 b의 내적은 0이다. 따라서 원래 길이의 제곱은 투영과 잔차 길이 제곱의 합으로 나뉜다.

03 / 분산이 큰 방향 찾기

채널별 평균을 빼서 Xc를 만든다. 공분산 S = XcᵀXc/N을 단위 방향 b에 투영한 분산은 bᵀSb다. 단위 길이 제약을 결합해 미분하면 고유값 문제가 된다.

핵심 식maxb bTSb   subject to   bTb = 1
∇b[bTSb−λ(bTb−1)] = 0
Sb = λb

가장 큰 고유값의 방향이 첫 주성분이다. 뒤 방향은 앞 방향과 직교하며 남은 분산을 최대한 보존한다. S = [[4,2],[2,4]]의 고유값은 6과 2, 방향은 대각선 두 개다. 첫 성분으로 전체 분산의 75%를 보존한다.

평균 제거와 표준화

큰 수치 스케일의 특징이 PCA를 지배할 수 있다. 단위가 다른 센서는 표준화가 적절한지 판단해야 한다. 이 실험은 채널 모두 같은 무차원 단위다.

04 / 버린 분산이 복원 오차인 이유

정규직교 기저 전체에서 좌표 제곱합은 관측 길이 제곱과 같다. 상위 k개 성분으로 복원하면 잔차에는 남은 좌표만 있다. 관측에 대해 평균을 취하면 버린 방향의 분산 합이 된다.

핵심 식X̂ = XcBkBkT
(1/N)‖Xc−X̂‖F² = Σj=k+1Dλj

오차는 관측마다 모든 특징의 제곱오차를 합한 평균이다. 특징까지 평균한 MSE는 D로 더 나눠야 한다. 공분산에 N−1을 쓰면 고유값 합에도 (N−1)/N을 곱해야 현재 정의와 맞는다. 표준화된 공간의 오차와 원래 단위 오차도 구분한다.

05 / SVD에서 같은 방향 얻기

Xc = UΣVᵀ이면 공분산은 V(ΣᵀΣ/N)Vᵀ다. V의 열은 PCA 방향이고 σⱼ²/N은 분산이다. 공분산을 먼저 만들지 않아도 SVD로 PCA를 구할 수 있다.

핵심 식Xc = UΣVT,   λj = σj²/N
Xk = UkΣkVkT

잘린 SVD는 주어진 랭크 이하에서 Frobenius 오차를 최소화하는 근사다. PCA는 중심화한 데이터에 이를 적용한다. 고유값이 같으면 해당 부분공간 안의 방향이 유일하지 않을 수 있다. 고유벡터 부호가 바뀌어도 투영·복원은 같다.

import numpy as np
rng = np.random.default_rng(431)
latent = rng.normal(size=(180, 2))
A = np.array([[1,.1],[.8,.4],[-.4,.9],[.2,-.8],[.6,.6],[-.7,.2]])
X = latent @ A.T + .35*rng.normal(size=(180, 6))
mu = X.mean(0)
centered = X - mu
U, s, Vt = np.linalg.svd(centered, full_matrices=False)
k = 2
restored = (centered @ Vt[:k].T) @ Vt[:k] + mu
error = np.sum((X-restored)**2)/len(X)
print(error, np.sum(s[k:]**2)/len(X))

06 / 압축과 잡음 제거의 차이

실험은 180개 관측과 6채널을 사용한다. 성분 수, 잠재 요인 상관, 잡음 크기를 바꾸며 보존 분산과 오차를 비교한다. 같은 데이터에 PCA를 맞추고 복원하므로 표본 내 압축 오차다.

잡음 제거 성능에는 깨끗한 기준 신호나 독립 평가가 필요하다. 성분이 많아지면 관측 복원 오차는 줄지만 깨끗한 신호에 더 가까워진다고 보장할 수 없다. 관측의 복원과 잠재 신호의 복원을 구분한다.

전체 성분을 쓰면 어떻게 되는가?

수치 오차를 제외하면 관측을 그대로 복원한다. 관측에 포함된 잡음도 함께 복원된다.

설명분산 95%면 분류 정보도 95% 남는가?

아니다. 작은 분산 방향에 목표를 구분하는 정보가 있을 수 있다. 후속 과제 성능으로 평가해야 한다.

심화 A / 신호 복원과 잡음 복원을 구분하기

심화 A · 성분 수와 잡음 제거

풀어볼 문제 PCA 복원 오차가 계속 줄어들면 깨끗한 신호도 계속 더 잘 복원되는 것일까?

시드 2505에서 두 잠재 요인 z~N(0,I₂), 6개 채널 x=Az+ε, ε~N(0,0.55²I₆)를 생성한다. A의 행은 [1,.2], [.8,−.4], [−.6,.7], [.2,1], [.7,.5], [−.5,−.8]이다. 훈련 180개와 독립 평가 400개를 만든다. 모든 특징은 무차원이다. 평균과 기저는 훈련에서만 추정한다.

핵심 식λⱼ=σⱼ²/N,   Bk=V[:,1:k]
x̂=(x−μtrain)BkBkᵀ+μtrain
  1. 훈련 중심화 행렬의 SVD를 구한다. 큰 두 고유값은 공통 요인, 나머지는 주로 관측 잡음을 반영하지만 유한 표본에서는 정확히 구분되지 않는다.
  2. k=0은 모든 입력을 훈련 평균으로 복원하는 기준선이다. k=1~6으로 늘리며 훈련 잡음 관측, 독립 잡음 관측, 독립 깨끗한 신호에 대한 제곱 잔차 노름 평균을 각각 계산한다.
  3. 이 실행에서 깨끗한 신호의 오차는 k=2에서 최소다. k=2의 오차는 0.601, k=6은 1.768다. 전체 성분은 잡음까지 완벽히 복원한다.
  4. 깨끗한 정답은 합성 실험이어서 알 수 있다. 실제 센서 데이터에서 이 지표를 그대로 사용할 수 없다면 반복 측정·신뢰할 수 있는 기준 신호·후속 작업 성능 같은 별도의 평가가 필요하다.
훈련에서 버린 고유값의 합은 독립 평가 오차와도 정확히 같은가?

그 항등식은 기저를 구한 중심화 훈련 행렬의 복원 오차에 대해 성립한다. 다른 관측의 공분산과 평균은 달라질 수 있으므로 독립 평가 오차에는 같은 수치 등식이 일반적으로 성립하지 않는다.

심화 B / 단위 변경이 PCA 방향에 미치는 영향

심화 B · 단위 변경과 표준화

풀어볼 문제 채널 3의 표시 단위만 20배로 바꾸었는데 첫 주성분이 달라졌다. PCA가 잘못된 것일까?

앞의 훈련 관측에서 채널 3만 20배로 바꾼다. 정보는 같은데 수치 단위가 달라진 상황이다. 중심화만 한 PCA와, 훈련 채널 표준편차로 나눈 PCA의 첫 성분을 비교한다. 그림은 부호 불확정성을 없애기 위해 첫 고유벡터 성분의 제곱을 사용한다.

  1. 중심화는 위치를 옮길 뿐 척도를 맞추지 않는다. 한 특징을 20배 늘리면 그 분산은 400배가 되고 다른 특징과의 공분산도 변한다.
  2. 표준화하지 않은 첫 성분에서 채널 3의 제곱 로딩은 99.7%다. 수치 크기가 큰 채널이 선택 방향을 거의 지배한다.
  3. 훈련 평균·표준편차로 Z=(X−μ)/s를 만든 뒤 PCA를 적합한다. 추론 때도 같은 μ,s를 사용한다. 두 그림의 로딩은 각각 원시 공간과 표준화 공간에서 정의된 값이다.
  4. 표준화가 늘 옳지는 않다. 작은 분산이 정밀 측정 신호인지, 거의 상수인 잡음 채널인지에 따라 단위 분산으로 확대하는 효과가 달라진다. 물리적 의미와 후속 목적을 함께 본다.
계산 코드의 핵심 펼치기

심화 Python의 해당 함수에서 발췌한 계산 흐름입니다. 전체 데이터 생성·보조 함수는 아래 다운로드에 있습니다.

mu = X_train.mean(axis=0)
sd = X_train.std(axis=0, ddof=0)
sd = np.where(sd == 0, 1, sd)
Z = (X_train - mu) / sd
_, singular, Vt = np.linalg.svd(Z, full_matrices=False)
B = Vt[:2].T
scores = ((X_valid - mu) / sd) @ B
restored = (scores @ B.T) * sd + mu
# 원 단위 평가: np.mean(np.sum((X_valid-restored)**2, axis=1))
표준화 공간에서 최소인 복원 오차는 원래 단위의 제곱오차도 최소로 만드는가?

일반적으로 아니다. 표준화 공간은 원 좌표 잔차를 채널 표준편차의 제곱으로 나눈 가중 오차를 최소화한다. 단위 선택은 최적화하는 거리의 의미를 바꾼다.

심화 C / 99.8% 분산 보존으로도 분류에 실패하기

심화 C · 정보 보존의 반례

풀어볼 문제 분산을 99% 넘게 보존했는데 분류 정확도가 동전 던지기 수준으로 떨어질 수 있을까?

x₁은 −8~8의 균등한 100개 격자 값이다. 각 x₁마다 y=−1,+1 관측을 하나씩 두어 총 200개를 만든다. x₂=0.2y로 둔다. x₁은 크게 변하지만 라벨과 독립이고, x₂는 아주 조금 변하지만 라벨을 완전히 결정한다. 이 사례는 난수가 없는 대칭 구성이다.

핵심 식Cov(x₁,x₂)=0,   Var(x₂)=0.04
PC1 방향=[1,0]ᵀ ⇒ x̂₂=0
  1. 첫 성분이 보존하는 분산은 99.8%다. 큰 x₁ 방향의 변동을 남기므로 압축 지표만 보면 매우 좋다.
  2. 원래 공간에서는 sign(x₂)만으로 모든 라벨을 맞춘다. 첫 성분으로 압축하면 동일한 x₁에 반대 라벨 두 개가 겹쳐 어떤 결정론적 분류기도 이 균형 집합에서 50%를 넘길 수 없다.
  3. 이 50%는 모델을 잘못 학습해서 생긴 수치가 아니라 표현이 두 라벨을 구분할 정보를 제거해서 생긴 한계다.
  4. 비지도 압축의 목적은 X의 분산·복원이다. 지도학습에서 쓸 표현이라면 성분 수와 전처리를 훈련 안에서 정하고, 분류 목적에 맞는 독립 평가까지 해야 한다.
설명분산 목표를 99%에서 99.9%로 바꾸면 이 반례에서는 어떤가?

이 구성에서는 첫 성분 비율이 약 99.8166%라 99.9%를 충족하려면 두 성분을 남겨야 한다. 하지만 일반적인 분산 임계값만으로 모든 데이터의 라벨 정보를 보존할 수 있다는 뜻은 아니다.
