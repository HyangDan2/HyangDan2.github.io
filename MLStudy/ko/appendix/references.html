평가와 데이터 누출

확률분포와 수치 확인

SciPy 공식 문서: Beta distribution. 밀도 정의와 CDF·분위수의 의미를 확인합니다. Beta–Bernoulli 갱신과 가우시안 예측 분산은 본문에서 유도했으며 다운로드 계산에는 SciPy를 사용하지 않습니다.

회귀와 정규화

PCA와 행렬 분해

제작과 재현

HD2Lab의 학습 아카이브를 위해 설명·합성 사례·JavaScript 계산·SVG 도표를 새로 작성했습니다. AI 작성 지원을 사용했으며 공개 문헌 대조, 계산 테스트와 화면 검증으로 검토합니다. 개인의 학습 경험이나 실제 서비스 수행 이력을 대신 작성하지 않습니다.

브라우저 런타임 의존성은 없습니다. 수식은 HTML의 위·아래첨자와 유니코드로 표현하며, 그래프는 SVG입니다. 실험은 모두 로컬에서 실행되고 입력을 전송하거나 저장하지 않습니다. JavaScript가 꺼지면 기본 설정에서 계산한 정적 결과를 표시합니다.

7개 장 Python 예제 다운로드 · Jupyter Notebook 다운로드 · 브라우저 수치 코드

심화 Notebook · 28개 그림 출력 · 심화 계산 Python · 그림 재생성 Python · 심화 수치 결과

심화 그림 28개는 NumPy 2.2.6과 Matplotlib 3.10.5로 사전 계산한 SVG입니다. Notebook의 모든 셀을 실행하면 같은 실험과 그림을 다시 생성합니다. Matplotlib은 제작 도구이며 웹 런타임에는 포함하지 않습니다. Matplotlib 라이선스 · NumPy 라이선스.

Python 계산 예제에는 NumPy, 심화 그림 재생성에는 Matplotlib도 필요합니다. Python과 JavaScript는 난수 생성기가 달라 같은 숫자의 시드라도 표본은 일치하지 않습니다. 별도 검증에서는 브라우저가 생성한 동일한 배열을 NumPy에 전달해 계산을 비교합니다.
