01 /のような条件でも、値は変わります。

仮想的な予約通知が、予定された時刻よりも数秒早くまたは遅く到着することを測定してみましょう。符号付きの時間オフセットは、同じ条件下でも異なります。観測値を平均値μ、既知の標準偏差σのガウス分布でモデル化すると、変動と平均値の推定を分離することができます。

02 /という確率は、その出来事に関するものであり、密度は位置に関するものです。

確率空間は、結果の集合Ω、事象の集合、そして確率密度で構成されます。確定変数とは、結果を数値として与える関数のことです。離散変数では、確率を加算し、連続変数では、区間密度を積分します。

重要な式P(a ≤ X ≤ b) = ∫abp(x)dx
F(t) = P(X ≤ t)

0,0.2]では、均一な分布の密度は5です。密度は1を超えることはありますが、全体の積分は1です。連続分布において、一点における確率は0です。したがって、p(x)を「正確にxになる確率」と読み取ることはできません。

ガウシアン密度p(x) = [1/(σ√(2π))] exp(−(x−μ)²/(2σ²))

μは位置を、σ²は広がりを表します。多次元共分散は、各方向における広がりの程度を示します。密度は、変数の単位が変われば、数値も変わります。

03 /の条件を逆転させる計算

もし、p(a,b) = p(a|b)p(b)とp(a,b) = p(b|a)p(a)の値を等しく保つなら、ベイズの定理が成り立ちます。分母は、可能な原因についての和や積として表されます。

重要な式p(θ|D) = p(D|θ)p(θ)/p(D)
p(D) = ∫p(D|θ)p(θ)dθ
要素 意味
辞書 p(θ) 観測前のパラメータに関するモデル
ウド p(D|θ) θ 固定したときの、観測の妥当性
死後 p(θ|D) 観測結果を反映したパラメータの分布

A リクエストです。 80%, B が 20% 担当しており、遅延確率はそれぞれ… 0.05,0.20 そういうふうに言えば、遅延がある場合は… B 確率は、以下のように表されます： 0.20×0.20)/(0.80×0.05+0.20×0.20) = 0.5 ダ。遅延が… B それがより一般的であるという事実だけで、多くの遅延要求が発生してしまいます。 B そうとは断言できない。

04 /の観測を最も理にかなっている平均値

オフセットがy = [2,3,4,3]秒である場合、それは条件付き独立変数となります。また、σ = 2秒という場合も同様です。尤度は密度の乗に相当し、ログ尤度はその和です。μとは無関係な項を引くと、二乗誤差が最小になるようになります。

重要な式log p(y|μ) = 定数 − (1/(2σ²))Σi(yi−μ)²
μ̂ML = (1/N)Σiyi = 3秒

MLE パラメータの分布ではなく、尤度が最も大きい点を選びます。 σ もし、ドミシアスがないのであれば、ガウジアンです。 MLE 分散の分母は、 N 不便な標本分散の分母 N−1 目的が異なります。

05 /という値は、観測された値に、事前に設定された分布の値を加えたものです。

μの事前分布を、平均値がμ₀ = 0、分散がτ² = 1のガウス分布として扱います。尤度とその二乗を合計し、μに関する二乗和を求めると、事後分布もまたガウス分布になります。分散の逆数である精度も加わります。

重要な式vpost = (1/τ² + N/σ²)−1
mpost = vpost(μ₀/τ² + Σiyi/σ²)

上記の観測結果では、vpost = 1/2, mpost = 1.5も同様です。ガウス分布の平均値と最小値が同じであるため、MAPも1.5と同じです。次の観測値の予測分散はσ² + vです。post = 4.5という値は、観測されるノイズや、平均推定の不確実性を含んでいます。

import numpy as np
y = np.array([2.,3.,4.,3.])
sigma2, prior_var, prior_mean = 4., 1., 0.
post_var = 1/(1/prior_var + len(y)/sigma2)
post_mean = post_var*(prior_mean/prior_var + y.sum()/sigma2)
print("MLE:", y.mean(), "MAP:", post_mean)
print("predictive variance:", sigma2 + post_var)

06 / MAPと正則化の関係性

回帰ノイズが独立変数N(0,σ²)であり、傾きの係数の事前分布が独立変数N(0,τ²)の場合、負の対数後ろ向分布は、二乗オーダーがL2の合計に等しくなります。切片については、ここではポイント付けは行われません。

ジャンサの平方和 Ridgeとの対応−log p(θ|X,y) = 定数 + ‖y−Φθ‖²/(2σ²) + ‖θ傾けること‖²/(2τ²)
α = σ²/τ²

関係は、モデリングの仮定や損失のスケールが指定された時に成立します。MAPという点は、全体的な後ろ向不確実性を表すものではありません。

サンプル数が増えると、予期せぬ影響はどのようになるのでしょうか？

このガウス分布の例では、分散を固定にすると、N/σ²が大きくなり、事後平均が母集団平均に近くなります。

MAPは、MLEよりも常に優れているのでしょうか？

いや、間違った強力な辞書は、予測の精度を悪化させる可能性があります。サンプル数や複雑さ、そして仮定の適合性を確認する必要があります。

発展 A /の失敗確率の事後分布を順序付けして更新する

発展版 A · 順序付きベイズ更新

考える問題 20 この度の要求で、失敗が発生しました。 2 次に、以下の内容です。 80 ここで 7 失敗の確率を、単なる比率ではなく、分布として表現してみよう。

要求の失敗を条件付き独立なBernoulli(p)と仮定します。事前分布はBeta(2,18)、平均0.1です。最初の20件で失敗2件を観測するとBeta(4,36)、続く80件で失敗7件を加えるとBeta(11,109)になります。固定された架空の集計で、乱数によって集計を変えません。

重要な式p(p|s,n) ∝ pa+s−1(1−p)b+n−s−1
Beta(a,b) → Beta(a+s,b+n−s)
E[p|D]=(a+s)/(a+b+n),   P( 次の失敗 | D)=E[p|D]
  1. ウドpˢ(1−p)ⁿ⁻ˢを、辞書のべき乗に掛けます。失敗と成功の数は、それぞれBetaパラメータに加えられます。
  2. 前の事後分布を次のブロックの事前分布に使います。最終パラメータはa=2+2+7=11、b=18+18+73=109です。100件を一度に処理しても同じ結果です。
  3. 事後平均は9.2%で、次の1件が失敗する予測確率も同じです。失敗確率p自体の95%等裾信用区間は約4.7%~14.9%です。
  4. 区間の端点は事後密度を数値積分した累積分布の2.5%・97.5%分位点です。「このモデルと観測を条件として、pがこの区間内にある事後確率が95%」と読みます。次の100件の失敗回数の区間とは異なります。
段階 分布 平均値 95% 信用限度の範囲
観測前 Beta(2,18) 10.0% 1.3% ~ 26.0%
20回の観測後 Beta(4,36) 10.0% 2.9% ~ 20.9%
100回の観測後 Beta(11,109) 9.2% 4.7% ~ 14.9%
時間が経過するにつれて、実際の失敗率が変わっても、観測値を単純に積み重ねていくだけでよいのでしょうか？

固定されたpと条件付き独立の仮定が一致しない場合、古い観測結果は現在の状態を歪めます。区間ごとのモデル、時間変化モデル、または忘れ去り重みを別途設計し、時間の順序に沿って評価する必要があります。

発展されたB ·の基本率と非対称的な損失

考える問題 検出感度 90% もし警報が鳴った場合、故障する確率も高くなります。 90% そして、いつ対処すべきか、その時期はいつなのでしょうか？

架空の点検システムで故障率π=2%、感度90%、特異度96%と仮定します。10,000件の期待回数で考えると、故障200件中180件が警報、正常9,800件中392件が誤警報です。これはモデルによる期待回数で、第1章の乱数スコア標本とは別の計算です。

重要な式P(故障|警報=0.9π / [0.9π+0.04(1−π)]
π=0.02 ⇒ 180/(180+392) ≈ 31.5%
  1. まず、条件付き確率の方向を記述します。感度はP(警報|故障）であり、興味深い確率はP(故障|警報）です。
  2. 警報が発令されている状況下で、実際に故障が発生した割合には、正常な状態で発生した過剰な警報も含まれています。基準値が低い場合、この項目は大きくなりうる。
  3. では、qを「補正された個別の故障発生確率」と呼ぶことにしましょう。正常な状態で対応するコストは1であり、故障が発生した場合のコストは25です。正しい対応を行うことによるコストは0と単純化されます。
  4. 1−qという予想される損失と、25qという無視できる予想される損失を比較すると、その結果はq>1/26≈3.85%になります。50%が自動的に適用されるわけではありません。同じ条件の場合、二つの行動による予想される損失は同じです。
SVMの決定点f(x)に、1/26を直接適用することができるか？

いや、f(x)は、この例の補正された確率qではない。確率の補正や、別途検証にかかるコストを考慮して、スコアの意思決定の閾値を決定する必要がある。確率の補正に使用されるデータも、最終的なテストとは別に扱われるべきだ。

発展 C · 平均不確実性と観測ノイズ

考える問題 平均遅延時間を非常に正確に把握していても、次の遅延時間が正確になるとは限りません。その理由を計算してみましょう。

遅延の変動は、yᵢ|μ~N(μ,4)秒²、μ~N(0,9)秒²として扱います。N=1,2,5,10,20,50,100,300では、すべての標本平均を2秒に固定し、標本サイズの効果のみを比較します。実際には、同じ乱数標本を累積して得られる結果ではなく、標本平均に基づく条件付き比較です。

重要な式vN=(1/9+N/4)−1,   mN=vN(2N/4)
μ|D~N(mN,vN)
ynew|D~N(mN,4+vN)
  1. 事後精度は、事前の精度1/9とデータの精度N/4の合計です。観測の数が増えるほど、平均値の事後分散は減少します。
  2. N=300では、平均の事後標準偏差は0.115です。次の観測における予測標準偏差は2.003であり、依然として約2です。
  3. 全体の分散の法則に基づき、条件付き観測値の分散4と、平均推定値による分散vNを足し合わせます。平均値の推定誤差と、個々の観測値におけるランダムな変動は、別の項目です。
  4. 観測のノイズを減らすためには、センサーやサービスプロセス自体を改善したり、説明力のある特徴を追加する必要があります。同じ分布のサンプルをさらに多く収集するだけでは、仮定される観測分散4は消えないのです。
計算コードの要点を開く

発展Pythonの対応する関数から計算の流れを抜粋しています。完全なデータ生成と補助関数は以下のダウンロードにあります。

n = np.array([1, 2, 5, 10, 20, 50, 100, 300])
posterior_variance = 1 / (1/9 + n/4)
posterior_mean = posterior_variance * (2*n/4)
mean_sd = np.sqrt(posterior_variance)
new_observation_sd = np.sqrt(4 + posterior_variance)
print(np.c_[n, posterior_mean, mean_sd, new_observation_sd])
