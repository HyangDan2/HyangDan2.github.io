The uniqueness of ranks and suns

If the columns of Φ form a linear independence, then the coefficients are unique. However, if the features are duplicated, or if all values of x are equal, then the coefficients may not be unique. It’s important to distinguish between the uniqueness of the predicted values and the uniqueness of the coefficients.

Create curves using the 04 / linear model.

If we expand the input to [1,x,x²,…,xᵈ]], we can create a curve by combining the coefficients linearly. Here, “linear” refers to the way in which the parameters used in the model are combined. The feature transformation determines the function that the model will use to describe the data.

Key equationz = 2x − 1,   φ(x) = [1,z,z²,…,zd]T
ŷ = Σj=0d θjzj

The experiment involves shifting the input to [−1,1] in order to reduce the difference in the magnitude of the coefficients at the base. The degree of d is equal to 1~9. However, this doesn’t address all the instabilities that arise in higher-order polynomials. Outside the range of learning, the base values can increase rapidly.

import numpy as np
rng = np.random.default_rng(1729)
x = rng.uniform(0, 1, 32)
y = 3 + 2*x + 7*x**3 + .7*rng.normal(size=x.size)
Phi = np.polynomial.polynomial.polyvander(2*x - 1, 3)
coef, _, rank, _ = np.linalg.lstsq(Phi, y, rcond=None)
query = np.array([.25, .75, 1.15])
pred = np.polynomial.polynomial.polyval(2*query - 1, coef)
print("rank:", rank, "prediction (ms):", pred)

When the observations are scarce or the characteristics are similar, the coefficients become very unstable. The L2 normalization assigns a cost to the magnitude of the coefficients. The constants are excluded from the calculation. As α increases, the pressure on the slope coefficient increases. In very large values of α, the model becomes closer to a simple average prediction.

Advanced C / Distinguish bootstrap intervals from prediction intervals

Advanced C · Bootstrap and Unpredictable Uncertainties

Problem to explore Does a narrow 95% interval around a curve also contain 95% of new observations?

First, fix the fixed order and α. Then, extract the training data and reconstruct it into 30 elements, with each reconstruction being based on 350 elements. Each time, the model is adjusted accordingly. By calculating the 2.5%·97.5%th percentile of the predictions for each x–350 pair, we can obtain the bootstrap interval for the average function estimation.

Key equationVar(ynew|D) = Var( Mean function estimation | D) + σ²
Here, we are dealing with synthetic experiments that involve understanding σ=0.45.
  1. In each bootstrap process, xᵢ,yᵢ) is extracted together with the other elements. If x and y are extracted separately, their relationship becomes disrupted.
  2. The confidence intervals for the average predictions indicate the variability in the estimates due to the estimation method. These intervals do not take into account the noise associated with the new observations.
  3. For each bootstrap prediction, the noise from the independent N(0,0.45²) terms is added, and then the distribution is recalculated. This is why the range of values that can be predicted using this method is generally wider.
  4. This interval is conditional on the selected order of steps, i.e., α. It does not take into account model selection uncertainties, incorrect equations, or unknown noise distributions. There is also a Monte Carlo error in the 350 percentile estimates. The inclusion probability for the periodic 95% values has not been verified.
If we increase the number of sessions from 350 to 3,500, will the statistical uncertainty of the average function itself also decrease by 1/√10?

No. The Monte Carlo error in the calculation of the distribution decreases, but the information provided by the 30 training samples remains the same. To reduce the uncertainty in the function estimation, it’s useful to collect more observations or use appropriate structural assumptions.
