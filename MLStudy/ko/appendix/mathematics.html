선형대수 · 해와 공간

벡터의 선형결합 Σαᵢvᵢ가 만드는 집합을 span이라고 한다. 0을 만드는 조합이 모든 αᵢ = 0뿐이면 선형독립이다. 공간을 생성하는 선형독립 집합이 기저, 기저 벡터 수가 차원이다. 랭크는 행렬의 독립인 열 수이며 독립인 행 수와 같다.

2u+v=5, 4u+3v=11에서 두 번째 행에 첫 행의 −2배를 더하면 v=1, 다시 u=2다. 행 교환, 0이 아닌 상수배, 다른 행의 배수 더하기는 해집합을 유지한다. 사다리꼴에서 피벗 없는 열의 변수는 자유변수다. 마지막 행이 [0,0|1]이면 모순으로 해가 없다.

핵심 식A = [[1,2,3],[0,1,1]]
Ax = 0 ⇒ x = t[−1,−1,1]T
rank(A) = 2,   dim ker(A) = 1

선형사상 T는 T(αu+βv)=αT(u)+βT(v)를 만족한다. 변환행렬의 j번째 열은 입력 기저의 j번째 벡터가 출력 기저에서 갖는 좌표다. 기저를 바꾸면 좌표와 행렬 표현이 바뀌지만 같은 사상을 나타낼 수 있다.

B,C가 정사각 가역 기저행렬일 때[T]C←B = C−1AB

단사이면 영공간에 0만 있고, 전사이면 열공간이 출력 공간 전체다. 둘 다 만족하면 전단사다. 회전행렬 [[cosθ,−sinθ],[sinθ,cosθ]]는 길이를 보존하고, [[2,0],[0,1]]은 첫 좌표를 늘린다.

기하 · 노름과 정사영

노름은 비음수·양의 정부호성, 절대 동차성, 삼각부등식을 만족하는 길이 함수다. x=[3,−4]의 L1 노름은 7, L2 노름은 5다. 내적은 노름을 유도하지만 모든 노름이 내적에서 나오지는 않는다. L1은 평행사변형 법칙을 만족하지 않는다.

Cauchy–Schwarz 부등식|xTy| ≤ ‖x‖₂‖y‖₂

직교행렬 Q는 QᵀQ = QQᵀ = I여서 길이와 각도를 보존한다. 0벡터는 모든 벡터에 직교하지만 정규화할 수 없다. 부분공간 U와 직교여공간 U⊥의 차원 합은 전체 차원이다. 모든 x를 두 공간의 벡터 합으로 유일하게 나눈다.

핵심 식P = B(BTB)−1BT   (B의 열이 독립)
P² = P,   PT = P

정사영은 주어진 부분공간에서 유클리드 거리를 최소화한다. P²=P만 만족하는 사영이 반드시 정사영은 아니다. 대칭성도 필요하다. PCA는 이 부분공간 자체를 데이터에서 선택한다.

행렬 분해 · 구조를 드러내기

행렬식은 정사각 선형변환의 부호 있는 부피 배율이다. 0이면 가역이 아니다. 2×2 행렬 [[a,b],[c,d]]의 행렬식은 ad−bc다. 삼각행렬은 대각 원소의 곱이고, 여인자 전개는 한 행의 원소와 부호 있는 소행렬식을 더하는 재귀식이다. trace는 대각 원소의 합이며 고유값 합과 같다.

핵심 식Av = λv,   v ≠ 0
A = VΛV−1   (독립인 고유벡터가 충분할 때)

모든 정사각 행렬이 대각화되지는 않는다. [[1,1],[0,1]]은 고유값 1이 중복되지만 독립 고유벡터가 하나다. 실대칭 행렬은 직교 기저로 대각화된다. 양의 정부호 행렬은 모든 0 아닌 x에서 xᵀAx>0이다.

Cholesky 분해[[4,2],[2,3]] = LLT,   L = [[2,0],[1,√2]]

대칭 양의 정부호 행렬의 Cholesky 분해는 선형계 풀이와 상관된 가우시안 표본 생성에 쓰인다. 직사각 행렬에도 가능한 SVD는 A=UΣVᵀ다. Vᵀ는 입력 방향을 바꾸고 Σ는 늘이거나 줄이고 U는 출력 방향을 바꾼다.

잘린 SVD의 최적 랭크-k 근사‖A−Ak‖F² = Σj>kσj²

예를 들어 diag(5,2,1)를 랭크 1로 근사하면 diag(5,0,0), 오차 제곱은 5다. 유사역행렬은 0 아닌 특잇값을 역수로 바꾼 VΣ⁺Uᵀ다. 수치적으로 작은 특잇값의 처리에는 허용오차가 필요하다.

미분 · 연쇄법칙과 역전파

f(x,y)=x²y+sin y의 기울기는 [2xy, x²+cos y]ᵀ다. 벡터 함수 g(x,y)=[x²+y,xy]ᵀ의 Jacobian은 [[2x,1],[y,x]]다. 입력이 2차원이고 출력도 2차원이라 2×2지만 일반적으로는 출력 수 × 입력 수다.

핵심 식Jf∘g(x) = Jf(g(x))Jg(x)

신경망의 한 층을 h=σ(Wx+b), 손실을 L로 쓰자. δ=(∂L/∂h)⊙σ′(Wx+b)이면 ∂L/∂W=δxᵀ, ∂L/∂b=δ, ∂L/∂x=Wᵀδ다. 이 정보를 이전 층으로 전달한다. 비선형 활성함수의 미분 불가능한 점에서는 구현이 선택한 부분기울기를 사용한다.

중심 차분 검증∂f/∂xj ≈ [f(x+hej)−f(x−hej)]/(2h)

확률 · 합, 조건부, 공분산

결합분포에서 다른 변수를 합하거나 적분하면 주변분포를 얻는다. 독립이면 결합이 주변분포 곱으로 분해되지만 상관이 0이라고 일반적으로 독립은 아니다. X가 대칭 분포이고 Y=X²이면 공분산이 0일 수 있어도 종속이다.

핵심 식E[X] = Σxxp(x)   또는   ∫xp(x)dx
Cov(X,Y) = E[(X−E[X])(Y−E[Y])]
Var(X) = E[X²]−E[X]²

공분산은 양의 준정부호다. 임의 a에 대해 aᵀΣa가 선형결합 aᵀX의 분산이라 음수가 될 수 없다. 다변량 가우시안에서는 공분산 0인 성분들이 독립이지만 이는 특별한 성질이다.

핵심 식N(x|μ,Σ) = exp[−½(x−μ)TΣ−1(x−μ)] / √((2π)Ddet Σ)

위 밀도식은 Σ가 양의 정부호일 때의 전체 공간 밀도다. 특이 공분산은 낮은 차원의 부분공간에 질량이 모이므로 역행렬·행렬식을 그대로 사용할 수 없다.

최적화 · 제약과 선형계획

등식 h(x)=0인 문제는 L(x,λ)=f(x)+λh(x)로 만든다. 적절한 정칙성 조건에서 최적점은 ∇f+λ∇h=0, h=0을 만족한다. u²+v²를 u+v=1 아래 최소화하면 2u+λ=2v+λ=0이므로 u=v=1/2, 최솟값 1/2다.

부등식 gᵢ(x)≤0에는 승수 λᵢ≥0과 상보성 λᵢgᵢ(x)=0이 추가된다. 활성 제약과 그렇지 않은 제약을 구분하는 KKT 조건이다. 볼록성과 정칙성 같은 조건을 확인해야 최적성 보장을 적용할 수 있다.

가상 두 작업의 처리량 배분max 3u+2v
u+v≤4,   2u+v≤5,   u,v≥0

가능 영역 꼭짓점은 (0,0),(0,4),(1,3),(2.5,0)이다. 목적값은 0,8,9,7.5여서 최적은 (1,3)이다. 선형계획은 선형 목적과 선형 제약을 갖는다. 가능 영역이 비거나 목적이 무한히 개선될 수도 있고 최적해가 여러 개일 수도 있다.

복습 문제

고유분해와 SVD는 언제 같은가?

실대칭 양의 준정부호 행렬에서는 고유값이 음수가 아니므로 고유벡터를 이용해 SVD를 구성할 수 있다. 일반 행렬에서는 특잇값은 항상 비음수지만 고유값은 음수·복소수일 수 있다.

훈련 데이터의 PCA 공분산 분모를 바꾸면 방향도 바뀌는가?

N과 N−1의 차이는 양의 상수배라 방향은 같고 고유값만 비례해 바뀐다. 오차 항등식의 스케일은 맞춰야 한다.

L1과 L2 중 어느 손실이 이상치에 더 민감한가?

큰 잔차에서 L2의 변화율은 잔차에 비례해 커지고 L1의 부분기울기 크기는 일정하다. 특정 데이터의 계수 변화나 안정성은 설계행렬과 해의 유일성까지 함께 봐야 한다.
