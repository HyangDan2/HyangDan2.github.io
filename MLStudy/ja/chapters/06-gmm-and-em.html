01 / 重複するリクエストの種類

サービス要求のサイズや処理時間を標準化した仮想的な座標を観測しよう。さまざまなタイプが混在している場合でも、各タイプがどれだけ観測結果を説明するかを計算することができる。GMMは、さまざまなガウス分布の重み付け平均によって、全体の分布をモデル化している。

この章の目標

混合比と責任度を区別し、E/M段階を計算する。初期化、成分数、数値の安定性は、ログ値と共に観察される。

02 /個の密度の重み付け合計

各成分は、平均値がμₖ、共分散がΣₖ、混合比がπₖである。πₖとは、観測前に各成分が選ばれる確率のことです。重み和は1であり、各密度の積分値は1であるため、混合密度の積分値も1となる。

重要な式p(x) = Σk=1KπkN(x|μk,Σk)
πk ≥ 0,   Σkπk = 1

等密度線は、共分散の固有ベクトルが軸方向を向いた楕円形の形状をしています。対角共分散は、軸に平行な形に限定されます。一方、完全共分散は回転を許容します。自由度が増えると、必要とされるサンプル数や安定性の管理も増えます。

03 / 観測後の所属確率

成分番号zは、観測されない潜在的変数です。観測された成分xᵢの後の確率をベイズの定理を用いて計算した値が、責任値rᵢₖです。混合比は全体のモデルに関わり、責任値は各観測値に関わります。

重要な式rik = πkN(xi|μk,Σk) / ΣjπjN(xi|μj,Σj)

2つの成分の重み付け密度が0.12と0.08の場合、その値は0.6と0.4となります。最大の値を表示することはできますが、正確な区別はできません。各観測値の合計値は1になるべきです。

非常に小さな密度

ログミルドを計算した後、log-sum-expに正則化します。m = max(aₖ)の場合、log Σexp(aₖ) = m + log Σexp(aₖ−m)となります。これは、オーバーフローを減らすための同じ式です。

04 / E-stepとM-step

観測値のログ値は、log内に成分が含まれているため、パラメータを一括して求めるのは難しいです。現在は、E-stepで重み付け統計を推定し、M-stepでパラメータの値を計算しています。

重要な式Nk = Σirik
μknew = Σirikxi/Nk
Σknew = Σirik(xi−μknew)(xi−μknew)T/Nk
πknew = Nk/N

観測結果が0,2,5]であり、どの成分の値が0.8,0.6,0.1]である場合、有効なサンプル数は1.5となり、新しい平均値は1.7/1.5 ≈ 1.133です。共分散の更新には、新しい平均値が使用されます。成分の値が大きい観測結果の影響は大きくなります。

05 /というログの度数が示していること

理想的な場合では、観測されるログ尤度はEMに依存しても減少しません。しかし、全尤度の最大値は保証されません。初期の平均値に基づいて、他の適合度に収束する可能性があります。無制限混合モデルの場合、ある成分の分散が一つの点に集中すると、尤度は無限大になることもあります。

重要な式ℓ(θ) = Σilog[ΣkπkN(xi|μk,Σk)]

実験では、共分散対角成分に10⁻⁶を加えることで特異性を低減します。純粋な最大尤度更新と、微妙に異なる場合があるため、尤度が低下したり、異常な値が出た場合は実験を中断します。訓練時の尤度が高くても、将来の予測が必ずしも良いとは限りません。成分の数は、別途検証を行うか、AIC·BICのように複雑さを反映する基準によって選択することができます。

群の番号には、順番は決まっていません。

成分の名前を変えても、同じ密度になることがあります。初期化が異なる場合でも、同じ番号を持つ場合は、同じグループとして扱います。

06 / の責任度の実装と観察

import numpy as np
# 行は観測、列は成分です。値はlog(pi_k) + log N(x_i)です。
logp = np.array([[-2.1,-2.5],[-900.,-902.]])
shift = logp.max(axis=1, keepdims=True)
q = np.exp(logp-shift)
r = q/q.sum(axis=1, keepdims=True)
print(r)
assert np.allclose(r.sum(axis=1), 1)

0は初期状態です。1,5,20,60に増やして、楕円と対数尤度を比較します。初期化を変更しても、データは固定され、初期の平均値のみが変わります。楕円は、各成分においてMahalanobis距離、2の線上にあります。これは、全体の混合密度の等高線ではありません。

責任を全て0や1に負わせるのが、良いのでしょうか？

重なっている分布の場合、中間値は自然に存在するものです。これは、現在のモデル内での確率値に過ぎず、モデル自体が正しいという保証はありません。

成分の数を増やして、トレーニングの効率を高めると、より良くなるのでしょうか？

表現力が向上するにつれて、過剰に適合性が高まってしまうことがあります。複雑さと独立性の評価も同時に確認する必要があります。

発展部分：A · いくつかの初期値とモデルの選択

考える問題 EM ログウドが増加したという事実だけで、最適な混合モデルを見つけたと言えますか？

シード2606で訓練210件と独立検証400件を生成します。混合比は[.4,.35,.25]、平均は[−1.2,0]、[1.1,.7]、[.3,−.9]です。各成分をx=μ+Lz、z~N(0,I₂)で生成し、Lは[[.7,0],[.35,.55]]、[[.7,0],[−.2,.5]]、[[.45,0],[0,.6]]です。共分散はLLᵀで、三つの集団は一部重なります。

重要な式2次元、full covariance GMMの自由パラメータの数
p=(K−1)+2K+3K=6K−1
BIC = −2ℓtrain + p log N
  1. K=1~5 それぞれを初期化します。 3,11,29,47 ロ 100 定期的に更新されます。初期の平均値は、観測データから無作為に抽出されます。共分散は、全ての訓練データの共分散であり、混合比は均等に設定されます。
  2. K=3の最終的なログレベルは、-572.284, -557.453, -557.453, -557.455です。単調に増加する場合でも、他の初期値よりも低いレベルで推移することがあります。
  3. 各Kにおいて、トレーニングログの尤度が最も高い実行を選びます。成分の数が異なる場合は、適合性の計算に加えて、パラメータの数も考慮する必要があります。独立検証における、観測ごとの平均ログ密度も別途計算されます。
  4. この実行の最小値 BIC は K=3 最大検証可能な平均対数密度も K=3 また、生成される成分の数を知ることは、合成実験における特権的な機能です。しかし、その二つの基準が必ずしも一致するわけではなく、また、実際の意味での集団の数を正確に把握することも保証されていません。

発展版のB /の責任値を、エントロピーに変換して再読します。

発展版のB ·のコラブランス値とエントロピー

考える問題 ある観測結果を、最もありそうな成分の色に合わせて塗り込めば、どのような情報が失われてしまうのでしょうか？

K=3の最高訓練済みの尤度モデルを使用する。責任値rᵢₖとは、この観測値と現在のモデルを条件とした、潜在成分の所属確率のことである。これは、正解ラベルに対する分類精度や、その観測値が正常である確率とは異なる。重なっている部分では、複数の成分が観測値をよく説明できる。

重要な式rᵢₖ=exp(aᵢₖ−logsumexp(aᵢ₁,…,aᵢK))
aᵢₖ=log πₖ+log N(xᵢ|μₖ,Σₖ)
Hᵢ=−Σₖrᵢₖ log rᵢₖ,   0≤Hᵢ/log K≤1
  1. r=[.98,.01,.01]と[.51,.48,.01]は、どちらも最初の成分としてhard assignmentに置き換えられます。しかし、2番目の成分については、最初の成分と2番目の成分の説明がほぼ同じです。
  2. 正則化されたエントロピー0は、1つの成分に完全に集中している場合の値です。一方、1は、K個の成分に均等に分かれている場合の値です。自然対数を使用して、0log0=0で定義されます。
  3. この訓練サンプルにおいて、最大許容値が0.7未満の観測は、13個あります。0.7は説明のための任意の基準であり、集団の数を選択するための基準ではありません。
  4. 大きなエントロピーは、各成分間の曖昧さを示しています。すべての成分から離れている、全体の密度が低い理想点においても、ある成分の相対的な責任度は高くなる可能性があります。したがって、理想点を検出する際には、対数密度を別途考慮する必要があります。
計算コードの要点を開く

発展Pythonの対応する関数から計算の流れを抜粋しています。完全なデータ生成と補助関数は以下のダウンロードにあります。

logp = gmm_logp(X, weights, means, covs)
shift = logp.max(axis=1, keepdims=True)
log_norm = shift + np.log(np.exp(logp-shift).sum(axis=1, keepdims=True))
responsibility = np.exp(logp-log_norm)
entropy = -np.sum(responsibility * np.log(np.maximum(responsibility, 1e-300)), axis=1)
normalized_entropy = entropy / np.log(len(weights))
assert np.allclose(responsibility.sum(axis=1), 1)
# 上記の点については、log_normも別途確認されます。

発展 C / の共分散崩壊の診断とその防止

発展 C · 共分散崩壊と数値的安定性

考える問題 平均値を一つの観測値に固定した場合、ガウス分布の分散はどのように変化するのでしょうか？そして、最大尤度はどのような誘惑に屈するのでしょうか？

2次元の等方体ガウス分布の平均値は、1/(2πσ²)です。もし、ある成分が観測され、その成分がσ→0にまで減少すると、その点の密度は無限大になります。他の成分が残りの観測を説明できるため、無制約のGMM尤度では、このような退化問題が生じます。

重要な式Σₖ ← (1/Nₖ)Σᵢrᵢₖ(xᵢ−μₖ)(xᵢ−μₖ)ᵀ + εI
本の発展実装：ε=10−6
  1. σ=1から10⁻³に減少すると、平均密度は100万倍にも増大します。つまり、高い密度を持つ点が必ずしも良い集団を意味するわけではないのです。
  2. 共分散対角要素にεを加えることで、正の符号を持つ行列の安定性が保証される。εは分散単位であり、すべての軸に対して固有値の下限を追加する効果がある。
  3. 今回のことです。 K=3 適合性の最小共分散固有値は、 0.1631 ロ 10⁻⁶ 十分に大きいこと。また、責任の値や有限性、ログオーディー変化量も同時に検証されます。
  4. この対称性の補正は、元々は無制限尤度の正確な表現です。 M-step すべてのデータにおいて、必ず減少が保証されるわけではありません。小さな成分の有効な観測数、固有値、尤度の減少を監視し、必要であれば、初期化や制約条件を再設計する必要があります。
すべての特徴を1,000倍にしても、ε=10⁻⁶の効果は変わらないのでしょうか？

同じではありません。特徴量を1,000倍に増やすと、共分散は10⁶倍になります。したがって、同じ絶対値εの場合、相対的な効果は非常に小さくなります。単位やスケールに合った補正値を定め、標準化されているかどうかも明記する必要があります。
