01 / 분리만으로 정해지지 않는 경계

가상 메시지를 링크 비율과 반복 토큰 비율로 표현해 두 종류로 구분한다고 하자. 데이터를 완전히 나누는 직선이 여러 개일 수 있다. SVM은 가까운 관측과 경계 사이 여유로 그중 하나를 선택한다.

이 장의 목표

점수에서 거리를 구하고 마진 제약을 유도한다. C와 커널의 역할을 구분하며 손으로 풀 수 있는 예제를 확인한다.

기본 개념 다음에는 심화 사례 3개 · 새 도표 4개심화 A / C와 이상치가 경계를 바꾸는 과정심화 B / KKT 조건으로 서포트 벡터 읽기심화 C / XOR를 비선형 특징으로 분리하기

02 / 점수와 거리는 다르다

f(x) = wᵀx + b의 부호가 클래스를 결정한다. w는 경계에 수직인 법선이다. 경계 위 두 점의 차이에 w를 내적하면 0이다. b는 스칼라이며 경계 위치를 바꾼다.

핵심 식경계: wTx + b = 0
부호 있는 거리: d(x) = (wTx+b)/‖w‖₂

w,b를 같은 양수로 곱하면 점수는 변하지만 경계와 거리는 그대로다. 점수 1은 거리 1이 아니다. w = [2,0], b = −2, x = [3,1]이면 점수 4, 거리 2다.

03 / 마진을 최대화하는 제약

분리 가능한 데이터에 라벨 −1,+1을 쓰고 가장 가까운 점의 yᵢf(xᵢ)가 1이 되도록 스케일을 고정한다. 각 쪽 마진은 1/‖w‖, 전체 폭은 2/‖w‖다.

핵심 식minw,b ½‖w‖²
subject to   yi(wTxi+b) ≥ 1

표준화 좌표의 음성 점 (−2,0),(−1,1), 양성 점 (1,1),(2,0)을 보자. w = [1,0], b = 0이면 제약을 만족하고 전체 마진은 2다. 가운데 두 점의 제약을 합하면 w₁ ≥ 1이므로 이보다 작은 노름은 불가능하다.

import numpy as np
X = np.array([[-2,0],[-1,1],[1,1],[2,0]], dtype=float)
y = np.array([-1,-1,1,1])
w, b = np.array([1.,0.]), 0.
scores = X @ w + b
assert np.all(y*scores >= 1)
print("predictions:", np.where(scores >= 0, 1, -1))
print("margin width:", 2/np.linalg.norm(w))

04 / 겹치는 관측을 허용하기

관측이 겹치면 hard margin은 해가 없을 수 있다. 슬랙 ξᵢ로 마진 침범을 허용하고 크기에 비용을 준다. C는 노름과 침범 비용의 상대 비중이다.

핵심 식min ½‖w‖² + CΣiξi
yif(xi) ≥ 1−ξi,   ξi ≥ 0
동치: ½‖w‖² + CΣimax(0,1−yif(xi))

ξ = 0은 마진 밖 또는 위, 0<ξ<1은 올바른 쪽의 마진 안, ξ>1은 잘못된 쪽이다. C가 크면 침범 비용을 더 중요하게 보지만 분리 불가능한 데이터가 hard margin 문제로 바뀌지는 않는다.

05 / 승수와 서포트 벡터

제약을 승수 αᵢ ≥ 0으로 결합하고 w,b로 미분하면 w는 관측의 가중합, αᵢyᵢ의 합은 0이 된다. 다시 대입하면 쌍대 문제를 얻는다.

핵심 식w = Σiαiyixi,   Σiαiyi = 0
maxα Σiαi − ½Σi,jαiαjyiyjxiTxj

soft margin은 0 ≤ αᵢ ≤ C다. αᵢ ≠ 0인 관측이 서포트 벡터다. soft margin에서는 마진 내부나 오분류 관측도 포함할 수 있으므로 모두 마진 선 위에 있다는 설명은 일반적으로 맞지 않는다.

06 / 커널과 평가

쌍대 문제의 내적을 적절한 양의 준정부호 커널로 바꾸면 특징 공간의 내적을 직접 특징을 만들지 않고 계산한다. RBF 커널은 exp(−γ‖x−z‖²)다. γ는 국소성을 바꾸며 C와 함께 검증한다.

메시지 특징은 같은 비율 단위여도 분산이 다를 수 있다. 스케일은 훈련에서 계산하고 검증에 적용한다. 클래스별 precision·recall과 혼동행렬을 확인한다. 결정 점수는 보정된 확률이 아니다.

w를 0으로 줄이면 마진이 무한히 커지는가?

제약을 만족해야 한다. w = 0이면 서로 다른 라벨의 마진 제약을 동시에 만족할 수 없다.

최대 마진이면 테스트 오차도 항상 최소인가?

마진은 학습 기준이다. 분포·잡음·특징 표현에 따라 일반화는 별도 평가해야 한다.

학습을 연결하면: 내적은 예측과 거리, 미분은 학습 방향, 확률은 불확실성을 만든다. 모델 가정을 명시하고 실험으로 확인하는 것이 공통 주제다.

심화 A / C와 이상치가 경계를 바꾸는 과정

심화 A · 이상치와 C의 상충

풀어볼 문제 훈련 정확도가 같은 세 SVM도 마진과 검증 결과는 다를 수 있다. 어떤 근거로 C를 선택할까?

시드 2707에서 클래스 −1,+1을 18개씩 만든다. x₁=y+0.6ε₁, x₂=0.4y+0.7ε₂이며 독립 표준정규 잡음을 사용한다. 훈련에 라벨 +1의 이상치 [−2.2,−1.2]를 추가해 37개로 만들고, 이상치 없는 생성식의 독립 관측 400개를 검증에 쓴다. 평균·표준편차는 이상치를 포함한 훈련에서만 구한다.

핵심 식minw,b ½‖w‖²+CΣᵢmax(0,1−yᵢ(wᵀzᵢ+b))
z=(x−μtrain)/strain
wraw=w/s,   braw=b−wrawᵀμ
  1. C=.03,.3,3을 같은 표준화 관측에 적합한다. C는 평균 hinge가 아닌 합 hinge 앞의 계수이고 절편에는 벌점을 주지 않는다.
  2. 그림의 경계는 비교를 위해 원래 x 좌표로 역변환한다. 함수 마진 f=±1과 원 좌표에서 보이는 거리, 학습 공간의 거리 1/‖w‖를 혼동하지 않는다.
  3. 큰 C는 마진 침범에 높은 비용을 매긴다. 서포트 벡터가 줄거나 경계가 회전해도 훈련 정확도 한 값은 같을 수 있다.
  4. 아래 검증은 정상 생성식에 이상치 없는 조건이다. 배포에서도 같은 조건이 타당한지 확인해야 한다. 세 값을 비교한 검증 정확도는 선택용 결과이며 독립 최종 테스트 성능으로 보고하지 않는다.
C 훈련 정확도 검증 정확도 SV 수 상대 원·쌍대 차이
0.03 97.3% 92.2% 32 0.00e+00
0.3 97.3% 90.5% 14 1.07e-08
3 97.3% 91.5% 8 3.33e-08
훈련 표본을 같은 분포에서 두 배로 늘려도 동일한 C의 정규화 효과가 정확히 같을까?

현재 목적은 hinge 합이므로 관측 수가 늘면 데이터 손실 항의 상대 크기도 달라진다. 평균 손실+λ‖w‖²/2 형태와 대응하면 λ=1/(CN)이다. 손실 스케일을 맞춘 비교인지 먼저 확인한다.

심화 B / KKT 조건으로 서포트 벡터 읽기

심화 B · KKT로 서포트 벡터 구분

풀어볼 문제 서포트 벡터는 모두 마진 선 위에 있는가? soft margin에서는 세 경우를 구분해야 한다.

C=0.3 모델을 사용한다. 함수 마진 mᵢ=yᵢf(xᵢ), 슬랙 ξᵢ=max(0,1−mᵢ), 쌍대 계수 αᵢ를 함께 읽는다. 수치 판정 허용오차는 10⁻⁶이다. α를 임의로 부여하지 않고 쌍대 제약을 유지하는 두 변수 좌표 갱신으로 계산한다.

핵심 식0≤αᵢ≤C,   Σαᵢyᵢ=0,   w=Σαᵢyᵢzᵢ
αᵢ(mᵢ−1+ξᵢ)=0,   (C−αᵢ)ξᵢ=0
계수의 경우 최적성 조건에서의 위치 해석
α=0 m≥1 손실을 늘리지 않고 경계에 영향을 주지 않는 점
0<α m=1 마진 위의 자유 서포트 벡터
α=C m≤1 마진 내부·경계 위·오분류일 수 있음
  1. 0<α
  2. 이 모델의 자유 서포트 벡터는 3개, 상한에 닿은 서포트 벡터는 11개다. m<0인 오분류는 hinge>1, 00이다.
  3. 원 목적 P와 쌍대 목적 D를 모두 계산한다. 쌍대 제약을 만족하면 D≤최적값≤P이므로 작은 (P−D)/max(1,P)는 근사 최적성을 확인하는 근거가 된다.
  4. 심화 구현은 최대 20,000회 갱신한다. 위 표의 차이가 10⁻⁵ 이하인지 확인한 뒤 해를 해석한다. 부동소수점 때문에 발생하는 약 10⁻¹⁶의 음의 차이는 표에서 0으로 표시한다.
계산 코드의 핵심 펼치기

심화 Python의 해당 함수에서 발췌한 계산 흐름입니다. 전체 데이터 생성·보조 함수는 아래 다운로드에 있습니다.

alpha = model['alpha']
w, b, C = model['w'], model['b'], model['C']
margin = y * (Z @ w + b)
primal = .5 * (w @ w) + C * np.maximum(0, 1-margin).sum()
dual = alpha.sum() - .5 * (w @ w)
assert abs(alpha @ y) < 1e-8
assert np.all(alpha >= -1e-8) and np.all(alpha <= C+1e-8)
assert np.allclose(w, (alpha*y) @ Z)
print((primal-dual) / max(1, primal))

심화 C / XOR를 비선형 특징으로 분리하기

심화 C · 비선형 특징과 커널의 관계

풀어볼 문제 직선으로 풀 수 없는 XOR 형태에 특징 하나를 추가하면 어떤 경계가 생기는가?

중심 [−1,−1], [−1,1], [1,−1], [1,1]에서 각각 18개씩 독립 N(0,0.16²I₂) 잡음을 더한다. 라벨은 각각 +1,−1,−1,+1이다. svm_experiment 함수의 동일 시드 2707에서 앞 실험 이후 생성한다. 기본 특징 [x₁,x₂]와 확장 특징 [x₁,x₂,x₁x₂]에 각각 C=1 선형 SVM을 적합한다. 이 비교에서는 특징을 표준화하지 않는다.

핵심 식φ(x)=[x₁,x₂,x₁x₂]ᵀ
f(x)=w₁x₁+w₂x₂+w₃x₁x₂+b
k(x,z)=φ(x)ᵀφ(z)=x₁z₁+x₂z₂+(x₁x₂)(z₁z₂)
  1. 부호가 같은 두 사분면에는 x₁x₂>0, 다른 두 사분면에는 x₁x₂<0이다. 새 좌표는 원래 두 축에 분산된 패턴을 직접 드러낸다.
  2. 이 고정 표본의 훈련 정확도는 원 특징 50.0%, 확장 특징 100.0%다. 훈련 표본 위 표현 능력 시연이며 일반화 성능 비교가 아니다.
  3. 3차원 특징 공간의 선형 경계는 원래 2차원에서 곡선이 된다. φ의 내적으로 정의한 k는 임의 계수 c에 대해 Σcᵢcⱼk(xᵢ,xⱼ)=‖Σcᵢφ(xᵢ)‖²≥0이어서 양의 준정부호 커널이다.
  4. 이 실험은 φ를 명시적으로 계산한 선형 SVM이다. RBF 커널을 구현했다는 뜻이 아니며 기존 브라우저 실험실도 선형 SVM을 유지한다. 실제 커널 비교에서는 C·커널 파라미터·스케일링을 함께 검증한다.
이 커널은 (xᵀz+1)²와 같은가?

다르다. 그 다항 커널에는 상수, 선형항의 계수, x₁²z₁²·x₂²z₂² 등의 항도 포함된다. 특징 맵과 내적을 직접 전개하여 어떤 항과 가중치를 사용하는지 확인해야 한다.
