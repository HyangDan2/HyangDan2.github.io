## 빌드는 항상 같은 자리에서 틀린다

이번에도 실패는 늘 같은 곳에서 나왔다. 로컬에서는 통과하는데 배포에서만 깨지는 것.

```bash
# 로컬에서는 통과, CI에서 실패
npm run build
# Error: ENOENT: no such file or directory, open 'dist/index.html'
```

원인은 단순했다. 빌드 스크립트가 **저장소 루트 기준 경로**를 쓰고 있었고, CI는 다른 작업 디렉터리에서 실행됐다. 스크립트 안에서 `process.cwd()`를 쓰는 대신 설정 파일 기준 상대 경로로 바꾸니 해결됐다.

> 경로 문제는 코드 문제가 아니라 실행 위치 문제인 경우가 훨씬 많다. 실패했을 때 제일 먼저 찍어 볼 것은 `pwd`다.
