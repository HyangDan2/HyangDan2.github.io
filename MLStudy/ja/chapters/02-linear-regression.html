01 /の負荷が増えるほど、発生する遅延も増えます。

架空のストレージ装置に要求が集中すると応答遅延が増えます。負荷xは0から1の無次元値で、遅延yの単位はmsです。生成過程は3 + 2x + 7x³に平均0のガウスノイズを加えます。実測値ではなく、非線形性を観察するための合成データです。

実験では生成式の代わりに複数の次数の回帰式を学習します。訓練誤差、検証誤差、データ範囲外の予測を比較すると、曲線をよく当てはめることと新しい観測をよく予測することの違いが分かります。

この章の目標

正規方程式を導出し、入力に非線形でも係数に関して線形になり得る理由を説明します。次数と正則化が予測をどう変えるか確認します。

02 /のデータが多い場合、方程式は成り立たなくなります。

直線 y = b + wx 観測値に代入すると、 b, w そこで、連立方程式が生じます。3つの観測値です。 0,2), (1,3), (2,5) それは、一つの直線上に正確に位置するわけではありません。すべての方程式を満たす代わりに、残差の二乗和を最小化します。

重要な式Φ = [1, x],   θ = [b, w]T
θ̂ = arg minθ ‖Φθ − y‖²

3つの点の最小二乗誤差の解は、 b = 11/6, w = 3/2 予測は、[ 11/6, 10/3, 29/6] 、ジャンカ y − ŷ は [ 1/6, −1/3, 1/6] つまり、傾きや切断面を少し変えても、二乗和がさらに小さくならない点です。

ランクとハイの唯一性

もし、Φの列が線形独立である場合、係数は一意です。特徴が重複している場合や、すべてのxが同じである場合には、係数が一意ではない可能性があります。予測値の一意性と、係数の一意性は区別して考える必要があります。

03 /を微分し、投影によって読み取る。

J = (Φθ − y)ᵀ(Φθ − y)を展開すると、θᵀΦᵀΦθ − 2θᵀΦᵀy + yᵀyが得られる。θを微分した結果の傾きを0で表すと、正常な方程式が得られる。

重要な式∇J = 2ΦT(Φθ − y) = 0
ΦTΦθ̂ = ΦTy
θ̂ = (ΦTΦ)−1ΦTy   (列が線形独立である場合

最初の式は、ジャンカがΦのすべての列と直交するということを意味します。予測ベクトルは、yをΦの列空間に正射影した結果です。この観点は、PCAへの射影とも関連しています。

実装において、直接行列を計算する必要はありません。ΦᵀΦは、条件数を二乗することで数値的な誤差を増大させることができます。ブラウザの実装では、Householder QRを使って計算し、Pythonの例では、NumPyの最小二乗法を利用しています。

04 / 線形モデルを使って曲線を作成する

入力を[1,x,x²,…,xᵈ]に拡張すると、係数の線形結合によって曲線を作成することができます。ここでの「線形」というのは、学習に使用されるパラメータがどのように作用するかを意味します。特徴変換とは、モデルが使用する関数の構造を決定するものです。

重要な式z = 2x − 1,   φ(x) = [1,z,z²,…,zd]T
ŷ = Σj=0d θjzj

実験では、入力値を[−1,1]]に置き換え、基底の数値の大きさの違いを減らします。次数がdの項は、1~9の項に置き換わります。しかし、これでは高次多項式のすべての不安定さを解決することはできません。学習範囲外では、基底値が急速に増大する可能性があります。 

import numpy as np
rng = np.random.default_rng(1729)
x = rng.uniform(0, 1, 32)
y = 3 + 2*x + 7*x**3 + .7*rng.normal(size=x.size)
Phi = np.polynomial.polynomial.polyvander(2*x - 1, 3)
coef, _, rank, _ = np.linalg.lstsq(Phi, y, rcond=None)
query = np.array([.25, .75, 1.15])
pred = np.polynomial.polynomial.polyval(2*query - 1, coef)
print("rank:", rank, "prediction (ms):", pred)

05 / 正規化と過剰なフィット

観測点が少ないか、または特徴が類似している場合、係数は大きく変動します。L2の正規化により、係数の大きさにコストが課される。切片は除外されます。αが大きくなるほど、傾き係数への影響力も大きくなります。また、非常に大きなαの場合は、平均値に近くなります。

重要な式J(θ) = ‖Φθ − y‖² + αΣj=1dθj²

ブラウザは、√α倍のスケールの行列を下に配置した拡張最小二乗問題をQRで解くことになります。特徴スケールが変われば、同じαの意味も変わります。特徴変換が固定されている状態で比較を行う必要があります。

変更する 確認する必要があります。 解釈の限界
段位の昇格 学習・検証における誤差の違い 検証の誤差は、単調に変化しない。
サンプル数の増加 曲線の安定性 同じ分布であるという前提が必要です。
正規化の増加 曲線・係数の変化 過度になると、偏りが増大します。
引き延ばし x < 0またはx > 1の曲線 検証誤差は、[0,1]で測定されます。
損失のスケール

αは、残差の二乗和に加えられます。平均二乗誤差にペナルティを加えるという定義と比較するためには、係数をNに合わせて換算する必要があります。

06 /の実験と理解の確認

  1. 基本的な3次のモデルにおいて、生成された方程式と予測される曲線との違いを確認します。
  2. サンプル数を12に減らし、1次元、3次元、9次元を比較します。また、傾向も見てみます。
  3. 同じデータを用いて、規格化された値を高くし、学習誤差と検証誤差を比較する。

検証用のデータは、別のシードで用意されています。 120 これは観測に基づくものです。同じ設定であれば、同じデータが得られます。この探索によって、最終的なテスト性能を保証するわけではありません。

3次の生成式であり、3次のモデルです。しかし、検証誤差が0ではないのはなぜでしょうか？

係数は、有限のノイズを伴うサンプルとして推定されます。また、検証の対象となる目標値にもノイズが存在します。生成式が正確であっても、観測される目標値に対する期待値の誤差は、ノイズの分散に相当する量が残ります。

学習の誤差は、学習の段階が上がるほど、必ず厳然と減少するのでしょうか？

正則化を行わずに、正確な最小二乗解を求める場合、重なり合う基底上での最小値は変化しません。しかし、正則化された解や数値誤差には、この記述をそのまま適用することはできません。

発展A / 不安定な係数をSVDとRidgeで説明する

発展版：A · 多変量性、およびSVD

考える問題 ほぼ同じセンサーを2つ使用したところ、シータの符号や大きさが大きく乱れてしまいました。予測ももう不可能な状態になってしまったのでしょうか？

2202, N=70からx₁~N(0,1), x₂=x₁+0.015ε₂, y=1+2x₁+0.4εᵧまでの範囲で、シードを作成します。ノイズは独立した標準正規分布に従います。切片には点を与えません。ほぼ同じ値を持つ列は、複数の係数の組み合わせによって説明できます。

重要な式Xc=UΣVᵀ ⇒ wridge=V diag(σⱼ/(σⱼ²+α)) Uᵀyc
σⱼ²/(σⱼ²+α): OLSに対する、その方向での縮小率
  1. 中心化された2つの特徴の特異値は、12.460, 0.093です。OLSは、小さい特異値の方向にある雑音を、1/σだけ増幅します。
  2. 同じです。 X 維持すること。 y 標準偏差 0.05 小さな雑音を 120 これは、サンプルバスティングではなく、回答者の干渉に対する条件付き感度に関する実験です。
  3. OLS その他 w₁ 標準偏差は、 0.417, Ridge α=1 では、 0.004 ええ。 OLS そこでも w₁+w₂ 標準偏差は、 0.006 小さいです。
  4. 観測点が位置するx₁≈x₂方向では、各係数の合計値が予測に影響を与えます。各係数を原因効果として解釈したり、x₁とx₂の値が大きく異なる領域に外挿すると、問題が明らかになります。
Ridgeの小さな特異値の方向を減らすことで、真の信号がなくなる可能性があるかどうか。

そうなることもあります。正則化を行うことで、分散は減少しますが、一方でバイアスは増加します。つまり、小さなパラメータ値が必ずしも無意味であるという意味ではありません。αは、検証の性能や必要とされる解釈に応じて選ばれます。

発展B / 次数と正則化を同時に選ぶ

発展されたB ·の複雑さと、正則化の両方の選択

考える問題 階層を高めた後、αのみを比較するのではなく、階層×αの格子を比較してみましょう。そして、選択されなかったテスト結果を残しておきます。

新しい独立標本でx~Uniform(−1,1)、y=1+1.8x−2x²+2.5x³+ε、ε~N(0,0.45²)を生成します。訓練30件、検証240件、テスト400件です。次数1~9とα∈{0,0.0001,0.01,0.1,1,10}の54候補を同じ検証集合で比較します。乱数の順序はregression_experiment関数のシード2202で再現します。

  1. 基準値は[1,x,…,xᵈ]]に固定します。各候補者については、訓練データのみを用いて評価を行い、その結果をMSEという行列に記入します。
  2. この実行の最小値は、次数3, α=0と、検証結果MSE 0.216です。正則化が必ず必要だとは限りません。そのため、α=0も候補として考慮されます。
  3. 選択したモデルをそのまま固定し、独立テストにおいてMSE 0.240を得る。ここでは、検証を加えて再学習を行っていないため、図とテスト結果は同じ係数に対応している。
  4. 訓練範囲外での予測は、点線で表される生成式と比較されますが、実際の問題ではその生成式を知ることはできません。検証性能が良くても、外挿の信頼性を保証することはできません。

発展C / ブートストラップ区間と予測区間を区別する

発展されたC ·のブートストラップと、予測不可能性

考える問題 曲線の周囲の95%区間が狭ければ、新しい観測も95%がその中に入るでしょうか？

先に選ばれた順番と、 α 固定する。訓練行を復元抽出し、 30 一人ずつ 350 再構築し、毎回新しいモデルに設定する。各… x そこから 350 予測のための 2.5%·97.5% 雰囲気を計算すると、平均関数推定のブートストラッピング区間が得られます。

重要な式Var(ynewD) = Var(平均関数の推定 | D) + σ²
ここでは、σ=0.45を知るための合成実験について説明しています。
  1. 各ブートストラップでは、xᵢ,yᵢ)を行単位で一緒に抽出します。xとyを別々に抽出すると、関係が破壊されてしまいます。
  2. 平均予測のバリアント区間は、係数推定における不安定さを示しています。新しい観測値には、ノイズも含まれています。
  3. 各ブートストラップの予測結果に、独立したノイズ成分N(0,0.45²)を加えた後で、再び中央値を計算します。これが、黄色い予測区間が一般的により広い理由です。
  4. この区間は、選択された周波数スケールαに応じて条件付けられています。モデルの選択の不確実性、誤った生成式、未知のノイズ分散は考慮されていません。また、350回の周波数スケールにおける推定値にもモンテカルロ誤差が存在します。周波数スケール95%における包含率については、検証されていません。
350 季節を変える 3,500 回路を増やすと、平均関数自体の統計的不確実性も高くなります。 1/√10 減少するのでしょうか？

いや、そうではない。モンテカルロ誤差が減少したとしても、30個の訓練用サンプルが提供する情報量は変わらない。関数の推定における不確実性を減らすためには、より多くの観測データを収集するか、適切な仮定を加える必要がある。
