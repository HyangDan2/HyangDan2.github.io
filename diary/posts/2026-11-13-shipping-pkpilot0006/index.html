빌드는 항상 같은 자리에서 틀린다

이번에도 실패는 늘 같은 곳에서 나왔다. 로컬에서는 통과하는데 배포에서만 깨지는 것.

# 로컬에서는 통과, CI에서 실패
npm run build
# Error: ENOENT: no such file or directory, open 'dist/index.html'

원인은 단순했다. 빌드 스크립트가 저장소 루트 기준 경로를 쓰고 있었고, CI는 다른 작업 디렉터리에서 실행됐다. 스크립트 안에서 process.cwd()를 쓰는 대신 설정 파일 기준 상대 경로로 바꾸니 해결됐다.

경로 문제는 코드 문제가 아니라 실행 위치 문제인 경우가 훨씬 많다. 실패했을 때 제일 먼저 찍어 볼 것은 pwd다.

구조는 결국 한 장으로 정리된다

허브를 네 개로 늘리면서 각 사이트가 서로를 어떻게 가리킬지 다시 정리했다. ApplicationHub, GameHub, TechnicalHub, 그리고 Diary. 공통 규칙은 세 가지다.

  1. 모든 페이지는 Web-HQ로 돌아오는 링크를 헤더에 둔다.
  2. 색은 #101110 배경에 #ff824f 액센트 하나만 쓴다.
  3. 새 프로젝트는 카드 한 장으로만 설명한다. 설명이 길어지면 그건 카드가 아니라 글이다.
