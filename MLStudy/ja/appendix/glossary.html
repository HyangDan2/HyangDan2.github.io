共通の記号

記号 意味
N, D 標本数、特徴数
X, xᵢ 観測行列、i番目の観測の列ベクトル
θ, w, b モデルパラメータ、重み、スカラー切片
Φ 基底変換を適用した計画行列
μ, Σ, σ² 平均、共分散、分散
λ, σⱼ 文脈により固有値または乗数、j番目の特異値
η, α, C 学習率、回帰の罰則、SVM違反費用
K, k 混合成分数、PCAで選択した成分数
ᵀ, ‖·‖F 転置、Frobeniusノルム
記号を文脈とともに読む

Σは共分散行列を表したり、総和記号と似た形で使われたりします。各式の定義を確認してください。SVDのΣは特異値行列です。

用語辞典

用語 説明
標本 / Sample 分析における一つの観測単位。このサイトではデータ行列の一行です。
特徴 / Feature 予測や構造分析に使う入力属性。
パラメータ / Parameter 定めたモデルの中で学習によって推定する値。
ハイパーパラメータ 次数、学習率、成分数のように学習の設定を定める値。
損失 / Loss 観測と予測の間の費用。目的に応じて定義します。
汎化 / Generalization 学習に使わなかった観測でも有用に働く性質。
バイアスと分散 モデルの仮定による系統的な誤差と、標本の変化による推定の変動。
ランク / Rank 行列の線形独立な列または行の数。
基底 / Basis 空間を張る線形独立なベクトル集合。
正射影 / Orthogonal projection 残差が部分空間に直交する最も近い射影。
固有値 / Eigenvalue 変換が特定の方向を保ちながら伸縮させる倍率。
特異値 / Singular value SVDにおける直交方向ごとの非負の尺度。
Jacobian ベクトル出力の各入力に対する1階偏微分の行列。
Hessian スカラー関数の2階偏微分の行列。
尤度 / Likelihood 観測を固定し、パラメータを変えて見た観測モデルの値。
事後分布 / Posterior 観測を反映したパラメータまたは潜在変数の分布。
精度 / Precision 分布の文脈では分散の逆数または共分散行列の逆行列。分類評価の適合率とは区別します。
説明分散 選択したPCA方向に保持される入力の分散。予測情報の割合ではありません。
負担率 / Responsibility 現在の混合モデルで、一つの観測に対する各成分の事後確率。
対数尤度 尤度の対数。条件付き独立な複数の観測の寄与を和で表します。
マージン / Margin SVM境界と近くの観測の間の幾何学的な余裕。
サポートベクトル SVMの双対係数が0でない観測。ソフトマージンでは内部の点も含みます。
カーネル / Kernel 特徴空間の内積を計算する関数。適切な半正定値条件が必要です。
正則化 / Regularization モデルの複雑さなどに罰則を加える方法。標準化とは区別します。
標準化 / Standardization 訓練データから得た平均と尺度で特徴座標を変換する前処理。
