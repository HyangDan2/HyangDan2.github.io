Credits and reproduction

For the learning archives of HD2Lab, we have created descriptions, synthetic examples, calculations related to JavaScript, and charts related to SVG. We also used support tools for writing AI. The content has been reviewed through public literature review, calculation tests, and screen verification. We did not use personal learning experiences or actual service implementation records as the basis for writing this content.

The browser has no external runtime dependencies. Formulas use HTML superscripts, subscripts, and Unicode; graphs are SVG. Experiments run locally without transmitting or saving inputs. Only language and theme preferences are saved. With JavaScript disabled, precomputed results for the default settings remain visible.
