01 / 길고 좁은 골짜기

두 좌표 u,v에 대해 J = (u² + κv²)/2인 지형을 생각하자. κ가 크면 v 방향은 가파르고 u 방향은 완만하다. 같은 보폭으로 움직이면 가파른 방향에서 골짜기를 넘어갈 수 있다. 모델 학습의 많은 어려움은 이런 서로 다른 방향의 곡률에서 생긴다.

이 장의 목표

02 / 편미분을 모으면 기울기

편미분은 다른 변수를 고정하고 한 변수만 움직일 때의 변화율이다. 기울기는 편미분을 모은 벡터다. 작은 이동 Δθ에 대한 함수 변화는 기울기와 이동의 내적으로 근사된다.

핵심 식∇J(u,v) = [u,κv]T
J(θ + Δθ) ≈ J(θ) + ∇J(θ)TΔθ

같은 유클리드 길이의 이동 중 음의 기울기 방향이 1차 근사를 가장 많이 줄인다. 너무 멀리 이동하면 근사가 깨진다. 기울기가 0이라고 최소점인 것도 아니다. u² − v²의 원점은 안장점이다. Hessian은 2차 편미분 행렬로, 정상점에서 양의 정부호이면 엄격한 국소 최소점이다.

03 / 합성함수의 변화율 전달

p = wx + b, L = (p − y)²/2를 보자. w는 예측 p를 거쳐 손실에 들어간다. 연결마다 변화율을 곱하면 최종 변화율을 얻는다.

핵심 식∂L/∂p = p − y,   ∂p/∂w = x
∂L/∂w = (p − y)x,   ∂L/∂b = p − y

x = 2, y = 5, w = 1, b = 0이면 손실은 4.5, w의 기울기는 −6이다. 학습률 0.1로 w,b를 함께 갱신하면 1.6,0.3이 되고 손실은 1.125다.

벡터 출력의 미분을 모은 Jacobian은 행이 출력, 열이 입력이다. Jf∘g = JfJg가 성립한다. 역전파는 전체 Jacobian을 만드는 대신 손실에서 출발한 벡터와 각 층의 Jacobian 곱을 거꾸로 계산한다.

04 / 학습률의 안정성 조건

이차 목적함수에서 u는 매번 1 − η배, v는 1 − ηκ배가 된다. 두 절댓값이 1보다 작아야 모든 시작점에서 원점으로 수렴한다.

이 실험의 정확한 수렴 조건θt+1 = θt − η∇J(θt)
ut+1 = (1 − η)ut
vt+1 = (1 − ηκ)vt
0 < η < 2/max(1,κ)

κ = 6이면 η는 1/3보다 작아야 한다. 0.15와 0.4를 비교해 보자. 경계값에서는 감소하지 않는 진동이 생길 수 있다. 일반적인 비선형 모델은 모든 지점의 곡률을 알기 어려워 손실 변화와 종료 조건을 함께 관리한다.

05 / 좌표 보정과 확률적 갱신

실험의 “축 보정”은 v 방향 기울기를 κ로 나누는 대각 전처리다. 두 방향이 같은 비율로 줄어든다. 적절한 좌표 변환으로 이해할 수 있다. 특징 표준화도 도움이 될 수 있지만 언제나 이 예제처럼 완벽한 보정이 되지는 않는다.

핵심 식θt+1 = θt − η diag(1,1/κ)∇J(θt)

SGD는 작은 무작위 배치로 전체 기울기를 추정해 계산 비용을 줄인다. 균일 표본 추출 등 조건에서 불편 추정량이 되지만 개별 단계 손실은 증가할 수 있다. 배치 크기와 학습률은 비용과 변동성을 함께 바꾼다.

import numpy as np
point = np.array([3., 2.])
kappa, rate = 6., .15
losses = []
for step in range(45):
    losses.append((point[0]**2 + kappa*point[1]**2)/2)
    point -= rate*np.array([point[0], kappa*point[1]])
print("final point:", point)
print("loss decreased:", losses[-1] < losses[0])

06 / 실험과 검증

곡률을 2,6,12로 바꾸며 안정적인 학습률 범위가 좁아지는지 확인한다. 같은 설정에서 축 보정 전후를 비교한다. 고정된 좌표 창 밖의 경로는 잘라 표시하며 손실이 10¹²를 초과하면 반복을 중단한다.

기울기의 구현은 어떻게 검증하는가?

각 좌표에 작은 h를 더하고 뺀 함수값 차이를 2h로 나눈 중심 차분과 비교한다. h가 너무 작으면 부동소수점 오차가 커진다.

아주 작은 학습률은 모든 문제를 해결하는가?

수렴이 느려질 수 있고 안장점, 국소 최솟값, 잘못된 기울기 문제를 모두 해결하지는 않는다.

심화 A / 회전된 골짜기에서 세 최적화법 비교하기

심화 A · 회전된 곡률과 모멘텀

풀어볼 문제 축과 평행하지 않은 좁은 골짜기에서 GD, 모멘텀, Newton은 어떤 경로를 택할까?

J(w)=½wᵀHw, H=R diag(1,30) Rᵀ이며 R은 36° 회전행렬이다. 시작점은 [3,−2]ᵀ, 최솟값은 원점이다. 80회 갱신으로 GD(η=0.06), heavy-ball 모멘텀(η=0.07, β=0.65), Newton(η=1)을 비교한다. 결정론적 실험이며 모든 좌표는 무차원이다.

핵심 식GD: wt+1=(I−ηH)wt
Momentum: vt+1=βvt+Hwt,   wt+1=wt−ηvt+1
Newton: HΔ=∇J(w),   w←w−Δ
  1. GD를 고유벡터 좌표로 옮기면 오차가 각각 1−ηλ만큼 곱해진다. η=0.06에서는 λ=1 방향이 0.94, λ=30 방향이 −0.8이어서 느린 감소와 진동이 함께 나타난다.
  2. 모멘텀은 이전 이동을 누적한다. η가 GD의 상한 2/30보다 커도 같은 단순 GD 조건을 그대로 적용할 수 없다. 각 고유방향의 특성식 r²−(1+β−ηλ)r+β=0의 근 크기를 확인해야 한다.
  3. 80회 후 손실은 GD 3.93e-05, 모멘텀 4.63e-15다. 이 수치는 지정된 이차식과 설정의 결과이며 모든 손실에서 모멘텀이 빠르다는 뜻은 아니다.
  4. Newton은 이 양의 정부호 이차식에서 정확한 Hessian을 풀어 한 번에 원점으로 간다. 큰 모델에서는 선형계 풀이 비용이 크고, 비볼록 문제의 Hessian은 같은 성질을 갖지 않을 수 있다.
현재 H에 대각 성분의 역수만 곱하면 Newton과 같아지는가?

아니다. 회전 때문에 비대각 성분이 0이 아니다. diag(H) 역수는 좌표별 크기만 조정하고 축 사이의 결합을 제거하지 못한다. 이 예제에서 Newton은 전체 H 선형계를 푼다.

심화 B / 로지스틱 기울기를 중심 차분으로 검증하기

심화 B · 로지스틱 손실의 기울기 검사

풀어볼 문제 직접 미분한 벡터 기울기를 신뢰하기 전에 수치 미분으로 점검해 보자.

절편을 포함한 6×3 설계행렬의 행은 [1,−2,.5], [1,−1,1], [1,−.5,−1], [1,.5,.2], [1,1,−.7], [1,2,1.2]다. y=[0,0,1,0,1,1], 검사점 w=[.2,−.3,.4]로 둔다. 정규화 없는 평균 이진 교차엔트로피를 사용한다.

핵심 식J(w) = (1/N)Σ[log(1+exp(xᵢᵀw))−yᵢxᵢᵀw]
∇J = Xᵀ(sigmoid(Xw)−y)/N
gⱼFD=[J(w+heⱼ)−J(w−heⱼ)]/(2h)
  1. log(1+exp(z))를 그대로 계산하면 큰 z에서 overflow가 날 수 있다. NumPy logaddexp(0,z)로 같은 값을 안정적으로 계산한다.
  2. 해석적 기울기는 [0.065, -0.534, 0.256]다. 열벡터 크기는 3이고 각 항의 부호는 해당 파라미터 증가 시 손실의 변화 방향을 나타낸다.
  3. h를 10⁻¹~10⁻¹⁰으로 바꿔 최대 절대 차이를 그린다. 이 실행의 최소 차이는 5.58e-12다. 너무 큰 h는 절단 오차, 너무 작은 h는 두 비슷한 값의 뺄셈 오차를 키운다.
  4. 여러 파라미터 지점과 입력 크기에서 검사한다. 한 지점의 일치만으로 전체 학습 코드가 맞다고 결론 내리지 않는다.
계산 코드의 핵심 펼치기

심화 Python의 해당 함수에서 발췌한 계산 흐름입니다. 전체 데이터 생성·보조 함수는 아래 다운로드에 있습니다.

def loss(w):
    z = X @ w
    return np.mean(np.logaddexp(0, z) - y * z)
p = 1 / (1 + np.exp(-(X @ w)))
gradient = X.T @ (p - y) / len(y)
h = 1e-5
numeric = np.array([(loss(w+h*e)-loss(w-h*e))/(2*h)
                    for e in np.eye(len(w))])
print(np.max(np.abs(numeric - gradient)))

심화 C / SGD의 잡음 바닥을 식으로 예측하기

심화 C · SGD의 잡음 바닥

풀어볼 문제 평균적으로 올바른 기울기를 사용해도 손실이 0으로 내려가지 않는 이유를 식으로 예측해 보자.

스칼라 손실 J(w)=λw²/2, λ=4를 사용한다. 미니배치 기울기를 g=λw+ξ, Eξ=0, Varξ=σg²/B로 모델링한다. σg=2, η=0.1, 시작 w=2다. 실제 데이터셋을 배치로 뽑는 대신 배치 크기에 따른 가우시안 기울기 잡음을 직접 생성한 단순화 실험이다. 시드 2303, 각 B마다 2,048개 독립 경로를 평균한다.

핵심 식wt+1=(1−ηλ)wt−ηξt
V∞=(1−ηλ)²V∞+η²σg²/B
E[J]∞=ησg² / [2B(2−ηλ)]
  1. 기울기 잡음이 현재 w와 독립이고 |1−ηλ|<1이면 유한한 정상 분산을 구할 수 있다. 여기서는 1−ηλ=0.6이다.
  2. 초기값의 효과가 사라진 뒤에도 매번 새 잡음이 들어오므로 상수 학습률은 일정한 손실 바닥을 만든다.
  3. B=1,16,64의 이론 손실 바닥은 각각 0.125, 0.0078125, 0.001953125다. 같은 학습률에서 배치를 16배 늘리면 이 단순 모델의 정상 손실은 1/16로 준다.
  4. 학습률을 줄여도 잡음 바닥은 낮아지지만 초기 수렴은 느려질 수 있다. 배치 증가의 계산 비용, 데이터 상관, 비선형 손실에서는 이 식을 그대로 성능 보장으로 쓰지 않는다.
잡음 없는 GD에서 η를 그대로 두면 이 손실 바닥도 남을까?

σg=0이면 이론적 정상 손실은 0이다. 안정 학습률의 결정론적 이차식에서는 초기 오차가 기하급수적으로 감소한다. 지금의 바닥은 상수 학습률로 새 기울기 잡음을 계속 주입해서 생긴다.
